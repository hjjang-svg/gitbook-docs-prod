# 픽셀 이벤트 테스트 가이드

<figure><img src="../../.gitbook/assets/image (5) (3).png" alt=""><figcaption></figcaption></figure>

토스애즈 관리자센터에서 픽셀 이벤트 테스트 기능을 사용할 수 있습니다.

픽셀 이벤트 테스트는 광고주 사이트에 설치한 웹 픽셀이 정상적으로 연결되어 있는지, 그리고 사이트에서 발생한 토스애즈 이벤트가 정상적으로 수집되는지 확인할 수 있는 기능입니다.

### 픽셀 이벤트 테스트란?

픽셀 이벤트 테스트는 사이트에 설치한 토스 웹 픽셀이 정상적으로 동작하는지 확인하는 기능입니다.

관리자센터에서 테스트할 사이트 URL을 열고, 사이트에서 이벤트를 발생시키면 수집된 이벤트 정보를 테스트 결과에서 확인할 수 있습니다.

이를 통해 다음 항목을 확인할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (6) (3).png" alt=""><figcaption></figcaption></figure>

| 확인 항목        | 설명                                                                                      |
| ------------ | --------------------------------------------------------------------------------------- |
| ❶ 테스트 대상 URL | 현재 테스트 중인 사이트 URL을 확인할 수 있습니다. URL이 다르면 `URL 변경`을 눌러 테스트할 사이트로 변경할 수 있습니다.              |
| ❷ 픽셀 연결 상태   | 테스트한 사이트에 토스 웹 픽셀이 정상적으로 연결되었는지 확인할 수 있습니다. 연결된 경우 테스트 결과 영역에 `연결됨` 상태와 연결된 도메인이 표시됩니다. |
| ❸ 수집된 이벤트    | 사이트에서 발생한 이벤트가 테스트 결과에 표시됩니다. 이벤트명과 이벤트 유형을 확인할 수 있습니다.                                 |
| ❹ 이벤트 받은 시각  | 이벤트가 수집된 시각을 확인할 수 있습니다. 여러 이벤트를 테스트할 때 어떤 행동에서 발생한 이벤트인지 구분하는 데 사용할 수 있습니다.            |
| ❺ 이벤트 상세 정보  | 이벤트가 발생한 URL, 매개변수 개수, 매개변수 값, 수신 경로, 토스 기여 여부를 확인할 수 있습니다.                             |
| ❻ 테스트 결과 초기화 | `결과 지우기`를 통해 현재 화면에 표시된 테스트 결과를 초기화하고 다시 테스트할 수 있습니다.                                   |

### 사용 전 확인 사항

이벤트 테스트를 시작하기 전에 아래 내용을 확인해 주세요.

1. 테스트하려는 사이트에 토스애즈 웹 픽셀이 설치되어 있어야 합니다.
2. 테스트하려는 이벤트가 사이트에 설치되어 있어야 합니다.
3. 관리자센터에서 확인할 픽셀의 전환추적 코드를 선택할 수 있어야 합니다.
4. 테스트할 사이트 URL에 접속할 수 있어야 합니다.
5. 이벤트 발생을 위해 상품 조회, 장바구니 담기, 회원가입, 구매 등 실제 테스트 행동을 수행할 수 있어야 합니다.

테스트 결과는 사이트 환경, 브라우저 설정, 네트워크 상태, 픽셀 설치 방식에 따라 반영 시간이 최대 1분까지 소요될 수 있습니다.

### 사용 방법

#### 1. 전환추적 코드를 선택합니다

<figure><img src="../../.gitbook/assets/image (7) (2).png" alt=""><figcaption></figcaption></figure>

토스애즈 관리자센터에서 테스트하려는 픽셀의 전환추적 코드를 선택합니다.

여러 개의 픽셀 또는 전환추적 코드를 사용 중이라면, 테스트하려는 광고주 사이트에 설치된 코드와 동일한 항목을 선택해야 합니다.

잘못된 전환추적 코드를 선택하면 이벤트가 정상적으로 발생해도 테스트 결과에서 확인되지 않을 수 있습니다.

#### 2. 이벤트 테스트 탭으로 이동합니다

<figure><img src="../../.gitbook/assets/image (8) (1).png" alt=""><figcaption></figcaption></figure>

선택한 전환추적 코드의 상세 화면에서 **이벤트 테스트** 탭으로 이동합니다.

이 화면에서 테스트할 사이트 URL과 테스트 결과를 확인할 수 있습니다.

#### 3. 테스트할 사이트 URL을 확인합니다

<figure><img src="../../.gitbook/assets/image (9) (4).png" alt=""><figcaption></figcaption></figure>

이벤트 테스트 화면에 표시된 사이트 URL이 실제 테스트하려는 사이트와 일치하는지 확인합니다.

URL이 다르다면 **URL 변경**을 눌러 테스트할 사이트 URL로 변경합니다.

URL을 변경한 뒤에는 해당 URL에서 테스트를 진행해 주세요.

#### 4. 테스트할 사이트에서 이벤트를 발생시킵니다

테스트할 사이트로 이동한 뒤 확인하려는 이벤트가 발생하도록 행동합니다.

설치 가능한 이벤트와 이벤트별 호출 방식은 [토스 픽셀 연동하기 가이드의 픽셀 표준 이벤트 리스트](https://toss-ads.gitbook.io/guide/resources/tosspixel)에서 확인할 수 있습니다.

#### 5. 테스트 결과를 확인합니다

<figure><img src="../../.gitbook/assets/image (10) (1).png" alt=""><figcaption></figcaption></figure>

이벤트가 정상적으로 발생 후 수집되면 테스트 결과에 이벤트 정보가 표시됩니다.

테스트 결과에서는 다음 정보를 확인할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (11) (2).png" alt=""><figcaption></figcaption></figure>

| 항목      | 설명                        |
| ------- | ------------------------- |
| ❶ 이벤트명  | 수집된 표준 이벤트 또는 이벤트 이름      |
| ❷ 수집 시각 | 이벤트가 관리자센터에 수집된 시간        |
| ❸ URL   | 이벤트가 발생한 페이지 URL          |
| ❹ 매개변수  | 이벤트와 함께 전달된 상세 값          |
| ❺ 수신 경로 | 이벤트가 어떤 경로로 수신되었는지에 대한 정보 |
| ❻ 토스 기여 | 해당 이벤트가 토스 기여로 확인되는지 여부   |

### 테스트 결과에서 확인할 수 있는 내용

#### 픽셀 연결 상태

<figure><img src="../../.gitbook/assets/image (12) (2).png" alt=""><figcaption></figcaption></figure>

웹 픽셀이 사이트에 정상적으로 연결되어 있는지 확인할 수 있습니다.

테스트 결과 영역에서 연결 상태는 `연결됨` 또는 `연결끊김`으로 표시됩니다.

* `연결됨`: 테스트한 사이트에서 픽셀이 정상적으로 감지된 상태
* `연결끊김`: 테스트한 사이트에서 픽셀이 감지되지 않았거나 이벤트 수집이 확인되지 않은 상태

이벤트가 표시되지 않는다면 다음 항목을 확인해 주세요.

| 확인 항목         | 설명                                  |
| ------------- | ----------------------------------- |
| 픽셀 설치 여부      | 사이트에 토스애즈 픽셀 코드가 설치되어 있는지 확인        |
| 전환추적 코드 일치 여부 | 관리자센터에서 선택한 코드와 사이트에 설치된 코드가 같은지 확인 |
| URL 일치 여부     | 테스트 화면의 URL과 실제 테스트한 URL이 일치하는지 확인  |
| 이벤트 발생 여부     | 사이트에서 실제로 이벤트가 발생하는 행동을 했는지 확인      |

#### 이벤트 수집 여부

<figure><img src="../../.gitbook/assets/image (13) (2).png" alt=""><figcaption></figcaption></figure>

사이트에 설치한 토스애즈 이벤트가 정상적으로 수집되는지 확인할 수 있습니다.

예를 들어 구매 이벤트를 테스트하는 경우, 구매 완료 페이지에 도달했을 때 구매 이벤트가 테스트 결과에 표시되어야 합니다.

이벤트가 표시되더라도 이벤트명이 예상과 다르거나 필요한 매개변수가 누락되어 있다면 설치 값을 다시 확인해야 합니다.

#### 이벤트 수집 시각

<figure><img src="../../.gitbook/assets/image (14) (2).png" alt=""><figcaption></figcaption></figure>

이벤트가 수집된 시간을 확인할 수 있습니다.

같은 이벤트를 여러 번 테스트하는 경우, 수집 시각을 기준으로 어떤 테스트 행동에서 발생한 이벤트인지 구분할 수 있습니다.

테스트 시에는 이벤트를 발생시킨 시간과 테스트 결과의 수집 시각을 함께 비교해 주세요. 이벤트가 수집되는 데 최대 1분까지 소요될 수 있습니다.

#### 이벤트 상세 값

<figure><img src="../../.gitbook/assets/image (15) (2).png" alt=""><figcaption></figcaption></figure>

이벤트 상세 화면에서는 이벤트와 함께 전달된 값을 확인할 수 있습니다.

주요 확인 항목은 다음과 같습니다.

| 항목       | 확인 방법                                   |
| -------- | --------------------------------------- |
| URL      | 이벤트가 의도한 페이지에서 발생했는지 확인                 |
| 매개변수     | 상품 ID, 가격, 통화, 주문 ID 등 필요한 값이 포함되었는지 확인 |
| 수신 경로    | 이벤트가 정상적인 경로로 수신되었는지 확인                 |
| 토스 기여 여부 | 해당 이벤트가 토스 기여로 확인되는지 확인                 |

매개변수는 캠페인 최적화와 성과 측정에 영향을 줄 수 있으므로, 필요한 값이 누락되지 않았는지 확인하는 것이 좋습니다.

### 토스 기여 여부 확인하기

<figure><img src="../../.gitbook/assets/image (16) (1).png" alt=""><figcaption></figcaption></figure>

테스트 결과에서 이벤트의 토스 기여 여부를 확인할 수 있습니다.

토스 기여 여부는 사이트에서 발생한 이벤트가 토스애즈 광고 유입과 연결되는지 확인하는 데 참고할 수 있는 정보입니다.

* `토스 기여: 예`: 토스애즈 광고 유입 정보가 유지된 상태에서 이벤트가 수집된 경우
* `토스 기여: 아니오`: 이벤트는 수집되었지만, 토스애즈 광고 유입 정보와 연결되지 않은 경우

`토스 기여: 아니오`로 표시되는 주요 원인 중 하나는 `tcid` 유실입니다. `tcid`는 광고 클릭 후 사이트로 이동하는 과정에서 토스애즈 광고 유입을 식별하는 데 사용되는 값입니다.

사이트 이동 과정에서 이 값이 유지되지 않으면 이벤트는 수집되더라도 토스 기여로 확인되지 않을 수 있습니다.

`토스 기여: 아니오`가 표시된다면, 먼저 광고 클릭 후 최종 이벤트 발생 페이지까지 `tcid`가 유지되는지 확인해 주세요.

`tcid` 보존이 필요한 경우 아래 가이드를 참고해 수정할 수 있습니다.

[tcid 보존 가이드](https://toss-ads.gitbook.io/guide/resources/tosspixel/preservationguide)

### 자주 발생하는 상황

#### 이벤트가 테스트 결과에 표시되지 않아요

아래 항목을 순서대로 확인해 주세요.

1. 관리자센터에서 올바른 전환추적 코드를 선택했는지 확인합니다.
2. 테스트 URL이 실제 이벤트를 발생시킨 사이트 URL과 같은지 확인합니다.
3. 사이트에 픽셀 코드가 설치되어 있는지 확인합니다.
4. 테스트하려는 이벤트가 해당 페이지 또는 버튼에 설치되어 있는지 확인합니다.
5. 브라우저의 광고 차단 확장 프로그램이나 추적 방지 설정이 켜져 있는지 확인합니다.
6. 이벤트 발생 후 잠시 기다린 뒤 테스트 결과를 다시 확인합니다.

#### 이벤트는 표시되지만 매개변수가 비어 있어요

이벤트 코드는 실행되었지만 상세 값이 전달되지 않았을 가능성이 있습니다.

상품 ID, 주문 금액, 통화, 주문 ID 등 이벤트별로 필요한 값이 정상적으로 전달되고 있는지 확인해 주세요.

#### 다른 이벤트가 표시돼요

사이트에서 의도한 이벤트가 아닌 다른 이벤트가 실행되고 있을 수 있습니다.

이 경우 다음을 확인해 주세요.

1. 테스트한 페이지에 어떤 이벤트 코드가 설치되어 있는지 확인합니다.
2. 버튼 클릭, 페이지 진입, 결제 완료 등 이벤트 발생 조건이 올바른지 확인합니다.
3. 동일한 페이지에서 여러 이벤트가 동시에 실행되는 구조인지 확인합니다.

#### 토스 기여 여부가 기대와 달라요

이벤트는 수집되었지만 `토스 기여: 아니오`로 표시된다면 광고 유입 정보가 이벤트 발생 시점까지 유지되지 않았을 수 있습니다.

광고 클릭 후 최종 이벤트 발생 페이지까지 `tcid`가 유지되는지 확인해 주세요. 자세한 내용은 위의 **토스 기여 여부 확인하기** 섹션을 참고해 주세요.

### 테스트 시 권장 방식

정확한 확인을 위해 아래 방식으로 테스트하는 것을 권장합니다.

1. 테스트할 전환추적 코드를 먼저 선택합니다.
2. 테스트할 사이트 URL을 관리자센터에서 확인합니다.
3. 광고 유입부터 이벤트 발생까지 하나의 브라우저에서 진행합니다.
4. 하나의 이벤트를 발생시킨 뒤 테스트 결과를 확인합니다.
5. 여러 이벤트를 테스트할 경우 이벤트별로 시간을 나누어 진행합니다.
6. 테스트 결과의 수집 시각과 실제 테스트 시간을 비교합니다.
7. 이벤트 상세 값에서 URL, 매개변수, 수신 경로, 토스 기여 여부를 함께 확인합니다.
8. 테스트 결과가 많아지면 `결과 지우기`로 초기화한 뒤 다시 테스트합니다.
