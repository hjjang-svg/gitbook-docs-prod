# 전환 추적 코드 생성

{% hint style="info" %}
디스플레이 광고의 전환 캠페인은 소재 검수 과정에서 '광고 목표별 필수 설치 이벤트'가 정상적으로 수집되는지 함께 확인하기 때문에, 검수 시간이 더 소요될 수 있어요.\
검수 시 필수 이벤트가 수집되지 않거나 이벤트 정보가 올바르지 않으면 소재 심사 승인이 불가해요.\
라이브 전에 필수 이벤트 설치와 수집 여부를 꼭 확인해 주세요.
{% endhint %}

전환 추적 코드를 생성할 광고 계정에 접속하여 광고 도구 > 전환 및 추적 연동 메뉴를 클릭해주세요.
