# 앱 설치 유도하기 소재 가이드

앱 설치 유도하기 광고의 소재를 만들 때 필요한 규격과 조건을 안내해요.

<figure><img src="../../.gitbook/assets/image (72).png" alt="앱 설치 유도하기 소재 예시"><figcaption></figcaption></figure>

## 앱 설치 유도하기 소재란?

앱 설치 유도하기는 앱 설치를 위한 광고 상품이에요. 전체 탭, 앱인토스, 게임 미니홈처럼 토스 안에서 앱 서비스 맥락이 있는 지면에 광고할 앱을 자연스러운 모습으로 보여주고, 유저가 앱을 눌러 설치하거나 참여하도록 유도해요.

소재는 앱 로고, 문구 세 가지, 연결 URL로 구성돼요. 모두 필수 항목이에요.

## 앱 로고

앱 서비스를 잘 드러내는 메인 이미지예요.

## 문구

문구는 한국어 앱명, 영어 앱명, 부제 세 가지를 입력해요.

#### 한국어 앱명

앱 서비스를 표현하는 제목이에요. 앱스토어 또는 플레이스토어에 등록된 앱명과 일치해야 해요.

<table><thead><tr><th width="220">규칙</th><th>내용</th></tr></thead><tbody><tr><td><strong>글자 수</strong></td><td><ul><li>공백 포함 1~20자 이내</li></ul></td></tr><tr><td><strong>사용 가능 문자</strong></td><td><ul><li>한글, 영문, 숫자, 공백</li><li><code>:</code> <code>∙</code> <code>?</code> 등 특수문자 허용</li><li>이모지 사용 불가</li></ul></td></tr></tbody></table>

#### 영어 앱명

앱 서비스를 표현하는 영문 제목이에요. 각 단어의 첫 글자를 대문자 또는 숫자로 쓰는 Title Case를 적용해주세요.

<table><thead><tr><th width="220">규칙</th><th>내용</th></tr></thead><tbody><tr><td><strong>글자 수</strong></td><td><ul><li>공백 포함 1~30자</li></ul></td></tr><tr><td><strong>사용 가능 문자</strong></td><td><ul><li>영문, 숫자, 공백</li><li><code>:</code> <code>∙</code> <code>?</code> 등 특수문자 허용</li><li>이모지 사용 불가</li></ul></td></tr></tbody></table>

#### 부제(보조 문구)

앱 서비스를 잘 설명하는 문구예요.

## 함께 입력하는 정보

소재를 등록할 때 카테고리 구분값도 함께 선택해요. 게임앱 또는 일반앱 중에서 선택하는 필수 항목이에요.

## 연결 페이지

광고를 누른 유저를 앱으로 연결하기 위해 링크 두 가지를 제출해요. 모두 필수 항목이에요.

#### 제출하는 링크 2종

<table><thead><tr><th width="220">링크</th><th>내용</th></tr></thead><tbody><tr><td><strong>랜딩 URL</strong></td><td><ul><li>유니버셜 링크(iOS)와 앱 링크(Android)를 지원하는, 전환 추적이 가능한 랜딩 URL이에요.</li><li>앱 성과 측정 도구(MMP)에서 딥링크를 적용해 생성한 트래킹 링크를 제출해요.</li></ul></td></tr><tr><td><strong>앱 스킴 (커스텀 URL 스킴)</strong></td><td><ul><li>앱이 설치된 상태에서 앱을 직접 실행하는 앱 스킴 링크예요. 예를 들어 <code>brandapp://event/123</code> 형태예요.</li><li>http, https 형식은 사용할 수 없어요.</li></ul></td></tr></tbody></table>

#### URL 규칙

<table><thead><tr><th width="280">규칙</th><th>내용</th></tr></thead><tbody><tr><td><strong>유저가 접속할 때 이상이 없어야 함</strong></td><td><ul><li>오류 ・ 접근 불가 페이지, 이벤트 오픈 전 페이지는 사용할 수 없어요.</li><li>이벤트 오픈 전 페이지로 심사를 받는다면 증빙 자료를 함께 제출해야 해요.</li><li>앱으로 랜딩된다면, 앱 미설치 유저는 앱 스토어 ・ 플레이스토어로 랜딩돼야 해요.</li><li>접속하는 데 5초 이상 걸린다면 브릿지 페이지 제작 여부를 확인해요.</li></ul></td></tr><tr><td><strong>랜딩 페이지의 내용과 소재 내용이 일치해야 함</strong></td><td><ul><li>랜딩 페이지에서 확인할 수 없는 혜택 ・ 정보는 사용할 수 없어요. 사용하면 심사가 반려돼요.</li><li>가입 ・ 응모처럼 조건이 있는 혜택은 광고 문구에 반드시 기재해야 해요.</li></ul></td></tr><tr><td><strong>URL 주소는 영문으로 제출</strong></td><td><ul><li>주소에 한글이 있으면 오류가 발생할 수 있어요.</li><li>링크 안에 <code>{ } ^ #</code> 문자가 있으면 반려될 수 있어요. <code>^</code> 대신 <code>_</code>(언더바) 사용을 권장해요.</li><li><code>http://</code>는 사용할 수 없어요. <code>https://</code> 사용을 권장해요.</li></ul></td></tr><tr><td><strong>URL 축약 불가, 원본(롱 링크) 제출</strong></td><td><ul><li>트래킹 링크는 파라미터가 보이는 원본 그대로 제출해요. 앱스플라이어 원링크도 파라미터가 단축되지 않은 원본을 제출해요.</li><li>숏 링크 ・ 단축 URL은 사용할 수 없어요(비틀리 포함).</li></ul></td></tr><tr><td><strong>필수 파라미터 포함</strong></td><td><ul><li>MMP별로 트래킹 링크에 반드시 포함해야 하는 파라미터가 있어요. 예를 들어 앱스플라이어 원링크는 <code>pid</code>, <code>advertising_id</code>, <code>click_id</code>, <code>af_c_id</code>, <code>af_ad_id</code> 파라미터를 포함해야 해요.</li><li>MMP별 필수 파라미터는 딥링크 설정 가이드에서 안내하고 있어요.</li></ul></td></tr><tr><td><strong>정상 동작 확인</strong></td><td><ul><li>제출하기 전에 링크가 중간 브라우저 화면 없이 앱을 바로 여는지 테스트해요.</li></ul></td></tr></tbody></table>

{% hint style="info" %}
두 가지 링크가 동작하려면 광고주 앱에 딥링크 구현과 MMP 설정이 먼저 필요해요. 준비하는 방법과 테스트하는 방법은 [딥링크 설정 가이드](link-guide.md)에서 안내하고 있어요.
{% endhint %}

## 소재 제작 공통 규칙

문구 표현, 이미지 표현, 광고 고지문구(심의필)처럼 여러 소재 유형에 공통으로 적용되는 규칙은 [배너 소재 가이드](../creative-guidelines/)에서 안내하고 있어요. 앱 설치 소재에도 동일하게 적용되니, 소재를 제출하기 전에 함께 확인해주세요.
