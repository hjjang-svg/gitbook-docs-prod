# 앱 설치 유도하기

앱 설치 유도하기는 유저의 **앱 설치와 실행**을 이끌어내는 토스 네이티브 광고예요. 이 문서를 따라 하면 앱 설치 유도하기 캠페인을 만들고, 광고 세트까지 설정해 광고를 집행할 준비를 마칠 수 있어요.

## 앱 설치 유도하기란? <a href="#app-install-overview" id="app-install-overview"></a>

앱 설치 유도하기는 앱 설치·실행 전환을 목적으로 하는 광고로, 유저가 광고를 통해 아웃랜딩으로 이동할 때 과금돼요. 유저가 광고를 누르면 앱 마켓 정보를 담은 브릿지 페이지(앱 소개 화면)로 이동해요. 다른 목표와 달리 등록 방식을 따로 고르지 않고, 하나의 플로우로 진행돼요.

### 광고를 만드는 3단계 구조

토스애즈에서 광고를 집행하려면 **캠페인 > 광고 세트 > 소재** 3단계를 등록해야 해요.

| 단계        | 설정하는 것                                      |
| --------- | ------------------------------------------- |
| **캠페인**   | 광고 목표, 집행 기간, 총 예산을 설정하고 하위 광고 세트·소재를 관리해요. |
| **광고 세트** | 일 예산, 입찰 방식, 타겟, 노출 일정을 설정해요.               |
| **소재**    | 유저에게 실제로 보이는 이미지·문구 등 크리에이티브를 설정해요.         |

{% hint style="info" %}
💡 소재를 만드는 방법은 [앱 설치 소재 가이드](creative.md)에서 따로 안내하고 있어요. 이 문서에서는 캠페인과 광고 세트까지 다뤄요.
{% endhint %}

## 시작하기 전 준비하기 <a href="#app-install-prerequisites" id="app-install-prerequisites"></a>

* **전환 및 추적 연동을 완료해주세요.**
  * 앱 설치 유도하기는 앱 설치·실행 성과를 측정하기 위해 앱 성과 측정 도구(MMP)를 이용하는 [앱 광고 성과 측정 연동(MAT)](../../tracking/mat/)이 필수예요. 캠페인을 만들기 전에 먼저 완료해 주세요.
* **앱 정보 수집 및 활용에 동의해주세요.**
  * 브릿지 페이지(앱 소개 화면)는 앱 마켓에 공개된 정보를 기반으로 구성돼요. 이를 위해 앱 정보 수집 및 활용 동의가 필수예요.
* **미리 준비할 정보**
  * 광고를 클릭한 유저를 앱으로 정확히 연결할 **랜딩 URL 2종**
    * 유니버셜 링크&앱링크를 모두 지원하는 전환 추적 가능한 랜딩 URL
    * 앱 스킴
  * 앱 로고·앱 이름·보조 문구 등 소재에 들어가는 정보
  * URL과 소재는 소재 단계에서 입력하며, 규격은 [앱 설치 소재 가이드](creative.md)에서 안내하고 있어요.

## 캠페인 만들기 <a href="#app-install-create-campaign" id="app-install-create-campaign"></a>

1. 좌측 메뉴에서 **캠페인 생성**을 눌러주세요.
2. 캠페인 목표에서 **앱 설치 유도하기**를 선택해주세요.
3. **앱 정보 수집 및 활용 동의**를 진행해주세요. 앱 설치 유도하기는 이 동의가 필수예요.
4. 아래 캠페인 정보를 입력해주세요.

| 입력 항목          | 안내                                                    |
| -------------- | ----------------------------------------------------- |
| **캠페인명**       | 관리하기 쉬운 이름으로 입력해주세요. 입력하지 않으면 `캠페인_생성일시`로 자동 저장돼요.    |
| **총 예산**       | 캠페인 집행 기간 동안 쓸 예산 한도예요. 100,000원 이상, 100원 단위로 입력해주세요. |
| **집행 기간**      | 광고가 노출되는 전체 기간이에요. 종료일을 두지 않으려면 **종료일 없음**을 선택해주세요.   |
| **전환 및 추적 연동** | 연동을 마친 전환 추적 코드를 선택해주세요. 연동이 완료된 코드만 선택할 수 있어요.       |

{% hint style="info" %}
💡 **심사 제출 후에는 캠페인 목표, 전환·추적 코드, 앱 정보 수집 및 활용 동의를 변경할 수 없어요.** 심사 제출 전에 다시 확인해 주세요.
{% endhint %}

## 광고 세트 만들기 <a href="#app-install-settings" id="app-install-settings"></a>

캠페인 하위에 광고 세트를 만들어 예산, 입찰, 타겟 조건을 설정해요.

**일 예산**

하루 동안 집행할 예산을 설정해요. 캠페인 총 예산 한도 안에서 설정할 수 있고, 이미 집행된 금액보다 적게는 설정할 수 없어요.

**입찰 방식**

앱 설치 유도하기는 **목표 전환당 비용(tCPA)** 자동 입찰을 지원해요. 목표로 정한 전환당 비용을 달성하도록, 전환 가능성이 높은 유저에게 자동 입찰해요.

{% hint style="info" %}
💡 **자동 입찰은 학습 시간이 필요해요.** tCPA는 머신러닝이 전환 데이터를 학습하며 입찰을 최적화하는 방식이라, 최적화까지 최대 일주일 정도 걸릴 수 있어요. 학습 초기에는 비용이 일시적으로 목표보다 높아질 수 있지만, 점차 목표 비용에 가까워져요. 다만 목표 비용이 너무 낮으면 예산이 소진되지 않고 전환도 잘 모이지 않을 수 있으니, 이 경우 목표 비용을 조금 올려보세요.
{% endhint %}

**타겟팅**

앱 설치 유도하기는 **오토 타겟팅**으로 운영돼요. 토스가 앱에 관심 가질 가능성이 높은 유저를 자동으로 찾아 노출해요.

* **오토 타겟팅**
  * 오토 타겟팅은 토스가 광고에 반응할 가능성이 높은 사용자를 자동으로 찾아 노출하는 방식이에요.
  * 연령·성별 등 세부 타겟을 직접 설정하지 않아도 되고, 기본적으로 전체 연령을 대상으로 해요.
  * 오토 타겟팅은 타겟을 자동으로 탐색하기 때문에, 예상 타겟 수는 미리 확인할 수 없어요.
  * **광고에서 제외할 대상 설정하기**
    * 오토 타겟팅을 사용할 때는, 광고를 노출하고 싶지 않은 대상을 제외할 수 있어요.
    * 연령, 성별, 고객 목록을 기준으로 제외할 수 있어요. (이 기능은 오토 타겟팅에서만 제공해요.)
    * 제외하는 대상이 적을수록 토스가 더 많은 사용자를 탐색할 수 있어, 광고 성과를 높이는 데 도움이 돼요.

{% hint style="info" %}
💡 **공통 준수 사항 - 성인 타겟팅**

* 성인 타겟팅은 성인(만 19세 이상)에게만 노출해야 하는 업종이나 광고일 때 사용하는 설정이에요.
* 성인 타겟팅을 사용하면 만 19세 이상에게만 광고가 노출되고, 미성년자(만 14\~18세)에게는 노출되지 않아요.
* 주류·담배·전자담배·데이팅·게임(성인 등급) 등 미성년자 보호 정책에 해당하는 업종·소재는 성인 타겟팅을 반드시 사용해야 해요. 자세한 대상은 [성인 타겟팅 필수 업종·소재](../../review/industryguide.md) 가이드에서 확인할 수 있어요.
* 성인 타겟팅 설정 후 광고 심사를 신청하면 설정을 바꿀 수 없으니, 심사 신청 전에 꼭 확인해 주세요.
{% endhint %}

**노출 기간, 노출 시간**

* 노출 기간
  * 광고 세트 노출 기간을 설정하실 수 있어요.
  * 캠페인 기간과 동일 옵션을 선택하실 경우 광고 세트가 속한 캠페인의 기간과 동일하게 노출이 진행돼요.
  * 광고 세트 노출 기간은 캠페인 집행 기간 이내로 설정할 수 있어요.
* 노출 시간
  * 상시 노출 값으로 기본 적용돼요.
  * 노출 시간대 설정을 클릭하실 경우 간단하게 노출 시간대를 설정할 수 있어요.
  * 요일별 시간대 설정을 클릭하실 경우 노출 요일과 시간을 설정할 수 있어요.

광고 세트까지 설정했다면, [앱 설치 소재 가이드](creative.md)를 참고해 소재를 등록하고 심사를 신청해주세요.
