## 잠재고객 모으기 캠페인(토스 양식 사용) 문구 기준

​[잠재고객 모으기 캠페인](https://app.gitbook.com/o/0jQIihOsngIZuei1colS/sites/site_b82pv/s/6C6VnjnrKC0ixISOKw0d/~/diff/~/changes/2089/a-d/lead-generation)에서 **토스 양식 사용(네이티브 광고)**&#xC744; 선택하면 배너에 아래 문구 작성 기준이 추가로 적용돼요. 유저가 배너만 보고도 **‘신청하면 무엇을 얻는지’** 알 수 있어야 해요.

{% hint style="info" %}
​[**토스 양식 사용(네이티브 광고)**](https://app.gitbook.com/o/0jQIihOsngIZuei1colS/sites/site_b82pv/s/6C6VnjnrKC0ixISOKw0d/~/diff/~/changes/2089/a-d/lead-generation#toss-form-flow): 아래에서 설명하는 추가 문구 기준을 적용해요.​[**URL로 사용**](https://app.gitbook.com/o/0jQIihOsngIZuei1colS/sites/site_b82pv/s/6C6VnjnrKC0ixISOKw0d/~/diff/~/changes/2089/a-d/lead-generation#url-flow): 이 전용 문구 기준은 적용하지 않고, 위의 문구 작성 기준과 문구 규격을 따라 주세요.
{% endhint %}

**작성 기준**

| 구분        | 작성 방법                       | 예시                                                                                           |
| --------- | --------------------------- | -------------------------------------------------------------------------------------------- |
| **주요 문구** | 유저가 받는 혜택이나 서비스 가치를 담아요.    | <ul><li><strong>인터넷 바꾸면 최대 145만원</strong></li><li><strong>답답한 채무 무료 상담 받기</strong></li></ul> |
| **보조 문구** | 혜택을 받기 위한 조건, 행동이 있다면 알려줘요. | <ul><li>신규 가입시 혜택</li><li>약정 끝난 인터넷</li></ul>                                                |

{% hint style="warning" %}
**주요 문구와 보조 문구 모두 문장을 `~고`, `~며`, `~면`, `~해서` 같은 연결어미로 끝낼 수 없어요.**
{% endhint %}

상품권·리워드·쿠폰 같은 현물성 혜택이 없어도 캠페인을 집행할 수 있어요.다만 혜택이 없다면 유저가 행동할 이유가 명확히 보이도록, 제공하는 **서비스 자체의 가치**가 문구에 드러나야 해요.

**특수문자**

* 배너 문구에는 `% + / . ~ , : - &`만 쓸 수 있어요.
* 특수문자는 비율, 상품 구성, 소수점, 범위, 금액, 시각, 고유명사처럼 다른 표현으로 바꾸기 어려운 경우에만 써 주세요.
* 주요 문구와 보조 문구의 끝에는 특수문자를 쓸 수 없어요.
* 강조하거나 꾸미기 위한 특수문자와 괄호는 쓸 수 없어요.
* 알파벳 `X`로 ‘없음’을 표시할 수 없어요. `없이`처럼 문장으로 풀어 써 주세요.
* 같은 특수문자를 강조 목적으로 반복해서 쓸 수 없어요. 다만 `1+1+1`처럼 숫자와 결합해 의미를 전달하는 경우에는 쓸 수 있어요.

## 예시

잠재고객 모으기로 등록한 한줄 배너는 토스앱의 최근본 딜, 혜택탭의 광고 지면에 아래와 같이 노출돼요.**주요문구 한 줄 만으로도 서비스의 가치가 드러나게 써 주세요.**

| <mark style="color:blue;">**`DO`**</mark> | <mark style="color:$danger;">**`Don't`**</mark> |
| ----------------------------------------- | ----------------------------------------------- |
| **내 보험 무료 점검** 모든 상담고객 무료                 | **보험 점검 신청** 지금 바로 신청하기                         |

**특수문자는 다른 표현으로 바꾸기 어려운 경우에만 써 주세요.**

| <mark style="color:blue;">**`DO`**</mark>                 | <mark style="color:$danger;">**`Don't`**</mark>     |
| --------------------------------------------------------- | --------------------------------------------------- |
| **생활용품 세트 1+1+1** 지금 구매하기​**오전 9:30 상담 예약** 10,000원 쿠폰 받기 | \[생활용품] 세트증정! 지금 구매하기\~​\[6월 한정] 상담 예약 -10,000 쿠폰 → |

**알파벳 `X` 대신 `없이`처럼 문장으로 풀어 써 주세요.**

| <mark style="color:blue;">**`DO`**</mark> | <mark style="color:$danger;">**`Don't`**</mark> |
| ----------------------------------------- | ----------------------------------------------- |
| **가입비 없이 무료 체험 신청** 맞춤 상담 받기              | 가입비 **X** 무료 체험 신청**하고** 맞춤 상담 받기               |
