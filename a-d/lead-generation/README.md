# 잠재고객 모으기

잠재고객 모으기는 질문 양식이나 외부 페이지로 유저를 유도해 **잠재고객을 확보**하는 광고예요. 이 문서를 따라 하면 잠재고객 모으기 캠페인을 만들고, 광고세트까지 설정해 광고를 집행할 준비를 마칠 수 있어요.

## 잠재고객 모으기란? <a href="#lead-generation-overview" id="lead-generation-overview"></a>

잠재고객 모으기는 잠재고객 확보를 목적으로 하는 광고로, 유저가 브릿지 페이지(혜택 소개 화면)에서 정보 입력으로 이어지는 버튼 클릭 시 과금돼요.&#x20;

캠페인을 만들 때 아래 두 등록 방식 중 하나를 선택하며, 등록 방식에 따라 준비물부터 과금·입찰·랜딩까지 달라져요.

* **토스 양식 사용:** 토스 안에서 바로 작성하는 고객 수집 양식으로 고객 정보를 수집해요.
* **URL로 사용:** 알리고 싶은 페이지의 외부 URL로 유저를 보내요.

{% hint style="info" %}
**등록 방식에 따라 사용할 수 있는 소재와 적용 기준이 달라요.**

**토스 양식 사용(네이티브 광고)**: 토스 안에서 고객 수집 양식을 작성해 정보를 수집해요. 한 줄 배너만 등록할 수 있고, 한 줄 배너 공통 기준에 더해 네이티브 광고 전용 문구 기준이 추가로 적용돼요. [한 줄 배너의 토스 양식 사용 추가 문구 기준 보기](../creative-guidelines/single-line-banner.md#lead-generation-copy)

**URL로 사용**: 알리고 싶은 외부 페이지로 유저를 보내요. 한 줄 배너·이미지·비디오 중에서 선택할 수 있어요. [URL 방식 배너 소재 가이드 보기](banner-guide/)
{% endhint %}

## 광고를 만드는 3단계 구조

토스애즈에서 광고를 집행하려면 **캠페인 > 광고세트 > 소재** 3단계를 등록해야 해요.

| 단계       | 설정하는 것                                     |
| -------- | ------------------------------------------ |
| **캠페인**  | 광고 목표, 집행 기간, 총 예산을 설정하고 하위 광고세트·소재를 관리해요. |
| **광고세트** | 일 예산, 입찰 방식, 타겟, 노출 일정을 설정해요.              |
| **소재**   | 유저에게 실제로 보이는 이미지·문구 등 크리에이티브를 설정해요.        |

{% hint style="info" %}
💡 이 문서에서는 캠페인과 광고세트까지 다뤄요. 소재 단계는 위 콜아웃의 등록 방식별 가이드에서 이어서 확인해 주세요.
{% endhint %}

## 등록 방식 선택하기 <a href="#choose-registration-method" id="choose-registration-method"></a>

두 방식은 준비물과 광고 운영 방식이 서로 달라요. 아래 표에서 차이를 먼저 확인하고, 목적에 맞는 방식으로 이동해 주세요.

| 비교 항목          | **토스 양식 사용**(토스 네이티브 광고)                 | **URL로 사용**                             |
| -------------- | ---------------------------------------- | --------------------------------------- |
| **이런 경우에 좋아요** | 토스 안에서 바로 상담 신청·정보를 받고 싶을 때              | 이미 운영 중인 외부 페이지로 유도하고 싶을 때              |
| **과금 시점**      | 브릿지 페이지(혜택 소개 화면)에서 정보 입력으로 이어지는 버튼 클릭 시 | 광고 배너 소재 클릭 시 (CPC)                     |
| **입찰 방식**      | 목표 전환당 비용(tCPA)                          | 자동 입찰(전환 최대)·목표 전환당 비용(tCPA)·직접 입찰(CPC) |
| **타겟팅**        | 오토 타겟팅                                   | 오토 타겟팅·직접 타겟팅                           |
| **소재**         | 한 줄 배너만 등록하고 고객 수집 양식을 설정                | 한 줄 배너·이미지·비디오를 직접 등록                   |
| **랜딩**         | 고객 수집 양식                                 | 단일 URL(아웃링크)                            |
| **필수 준비물**     | 소개 화면에 넣을 혜택·수집 정보                       | 전환 및 추적 연동                              |

***

## ‘토스 양식 사용’으로 광고 만들기 <a href="#toss-form-flow" id="toss-form-flow"></a>

### 시작하기 전 준비하기 <a href="#toss-form-prerequisites" id="toss-form-prerequisites"></a>

* **미리 준비할 정보**
  * 고객 수집 양식의 필수 **소개 화면**에 넣을 정보(혜택 안내, 수집할 항목 등). 소개 화면과 질문 양식은 소재 단계에서 설정해요. 자세한 기준은 [잠재고객 모으기 양식 가이드](creative.md)에서 확인할 수 있어요.
  * 소재에 사용할 문구·이미지

### 캠페인 만들기 <a href="#toss-form-create-campaign" id="toss-form-create-campaign"></a>

1. 좌측 메뉴에서 **캠페인 생성**을 눌러 주세요.
2. 캠페인 목표에서 **잠재고객 모으기**를 선택해 주세요.
3. 광고 등록 방식에서 **토스 양식 사용**을 선택해 주세요.
4. 아래 캠페인 정보를 입력해 주세요.

| 입력 항목     | 안내                                                     |
| --------- | ------------------------------------------------------ |
| **캠페인명**  | 관리하기 쉬운 이름으로 입력해 주세요. 입력하지 않으면 `캠페인_생성일시`로 자동 저장돼요.    |
| **총 예산**  | 캠페인 집행 기간 동안 쓸 예산 한도예요. 100,000원 이상, 100원 단위로 입력해 주세요. |
| **집행 기간** | 광고가 노출되는 전체 기간이에요. 종료일을 두지 않으려면 **종료일 없음**을 선택해 주세요.   |

### 광고세트 만들기 <a href="#toss-form-settings" id="toss-form-settings"></a>

캠페인 하위에 광고세트를 만들어 예산, 입찰, 타겟 조건을 설정해요.

**일 예산**

하루 동안 집행할 예산을 설정해요. 캠페인 총 예산 한도 안에서 설정할 수 있고, 이미 집행된 금액보다 적게는 설정할 수 없어요.

**입찰 방식**

토스 양식 사용은 **목표 전환당 비용(tCPA)** 자동 입찰을 지원해요. 목표로 정한 전환당 비용을 달성하도록, 전환 가능성이 높은 유저에게 자동 입찰해요.

{% hint style="info" %}
💡 **자동 입찰은 학습 시간이 필요해요.**\
tCPA는 머신러닝이 전환 데이터를 학습하며 입찰을 최적화하는 방식이라, 최적화까지 최대 일주일 정도 걸릴 수 있어요. 학습 초기에는 비용이 일시적으로 목표보다 높아질 수 있지만, 점차 목표 비용에 가까워져요. 다만 목표 비용이 너무 낮으면 예산이 소진되지 않고 전환도 잘 모이지 않을 수 있으니, 이 경우 목표 비용을 조금 올려보세요.
{% endhint %}

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2F7RGUS3334oJ2Ac5Y7M76%2Flead-generation-bid-20260727.png?alt=media&#x26;token=955b0a9d-ff0c-4b48-b87f-61fd3f9d69a8" alt="토스 양식 사용 광고세트에서 목표 전환당 비용을 설정하는 화면"><figcaption></figcaption></figure>

**타겟팅**

토스 양식 사용은 **오토 타겟팅**으로 운영돼요. 토스가 광고에 반응할 가능성이 높은 유저를 자동으로 찾아 노출해요.

* **오토 타겟팅**
  * 오토 타겟팅은 토스가 광고에 반응할 가능성이 높은 사용자를 자동으로 찾아 노출하는 방식이에요.
  * 연령·성별 등 세부 타겟을 직접 설정하지 않아도 되고, 기본적으로 전체 연령을 대상으로 해요.
  * 오토 타겟팅은 타겟을 자동으로 탐색하기 때문에, 예상 타겟 수는 미리 확인할 수 없어요.
  * **광고에서 제외할 대상 설정하기**
    * 오토 타겟팅을 사용할 때는, 광고를 노출하고 싶지 않은 대상을 제외할 수 있어요.
    * 연령, 성별, 고객 목록을 기준으로 제외할 수 있어요. (이 기능은 오토 타겟팅에서만 제공해요.)
    * 제외하는 대상이 적을수록 토스가 더 많은 사용자를 탐색할 수 있어, 광고 성과를 높이는 데 도움이 돼요.

{% hint style="info" %}
💡 **공통 준수 사항 - 성인 타겟팅**

* 성인 타겟팅은 성인(만 19세 이상)에게만 노출해야 하는 업종이나 광고일 때 사용하는 설정이에요.
* 성인 타겟팅을 사용하면 만 19세 이상에게만 광고가 노출되고, 미성년자(만 14\~18세)에게는 노출되지 않아요.
* 주류·담배·전자담배·데이팅·게임(성인 등급) 등 미성년자 보호 정책에 해당하는 업종·소재는 성인 타겟팅을 반드시 사용해야 해요. 자세한 대상은 [성인 타겟팅 필수 업종·소재](../../review/industryguide.md) 가이드에서 확인할 수 있어요.
* 성인 타겟팅 설정 후 광고 심사를 신청하면 설정을 바꿀 수 없으니, 심사 신청 전에 꼭 확인해 주세요.
{% endhint %}

**노출 기간, 노출 시간**

* 노출 기간
  * 광고세트 노출 기간을 설정하실 수 있어요.
  * 캠페인 기간과 동일 옵션을 선택하실 경우 광고세트가 속한 캠페인의 기간과 동일하게 노출이 진행돼요.
  * 광고세트 노출 기간은 캠페인 집행 기간 이내로 설정할 수 있어요.
* 노출 시간
  * 상시 노출 값으로 기본 적용돼요.
  * 노출 시간대 설정을 클릭하실 경우 간단하게 노출 시간대를 설정할 수 있어요.
  * 요일별 시간대 설정을 클릭하실 경우 노출 요일과 시간을 설정할 수 있어요.

광고세트까지 설정했다면, [잠재고객 모으기 양식 가이드](creative.md)에서 고객 수집 양식을 만들고 [네이티브 광고 전용 문구 기준](../creative-guidelines/single-line-banner.md#lead-generation-copy)에 따라 한 줄 배너를 등록한 뒤, [소재별 심사 정책](../../review/creativeguide.md)에 따라 심사를 신청해 주세요. 집행을 시작한 뒤에는 [성과 보기](../performance.md)에서 성과를 확인할 수 있어요.

### 광고세트 만들기 <a href="#url-settings" id="url-settings"></a>

캠페인 하위에 광고세트를 만들어 예산, 입찰, 타겟, 노출 조건을 설정해요.

**일 예산**

하루 동안 집행할 예산을 설정해요. 캠페인 총 예산 한도 안에서 설정할 수 있고, 이미 집행된 금액보다 적게는 설정할 수 없어요.

**입찰 방식**

URL로 사용은 아래 입찰 방식을 지원해요.

| 입찰 방식               | 동작 방식                                                         |
| ------------------- | ------------------------------------------------------------- |
| **자동 입찰 · 전환 최대**   | 일 예산을 최대한 소진하면서 전환을 가장 많이 얻도록 시스템이 자동으로 입찰해요.                 |
| **목표 전환당 비용(tCPA)** | 목표로 정한 전환당 비용을 달성하도록, 전환 가능성이 높은 유저에게 자동 입찰해요.                |
| **직접 입찰(CPC)**      | 클릭당 단가를 직접 설정해요. 설정한 값은 최대 비용이고, 경쟁 상황에 따라 실제 과금은 더 적을 수 있어요. |

{% hint style="info" %}
💡 **자동 입찰은 학습 시간이 필요해요.**\
자동 입찰 · 전환 최대와 tCPA는 머신러닝이 전환 데이터를 학습하며 입찰을 최적화하는 방식이라, 최적화까지 최대 일주일 정도 걸릴 수 있어요. 학습 초기에는 비용이 일시적으로 목표보다 높아질 수 있지만, 점차 목표 비용에 가까워져요. 다만 목표 비용이 너무 낮으면 예산이 소진되지 않고 전환도 잘 모이지 않을 수 있으니, 이 경우 목표 비용을 조금 올려보세요.
{% endhint %}

**타겟팅**

광고 타겟을 **오토 타겟팅**과 **직접 타겟팅** 중에서 선택해 설정해요. 최적화된 자동 타겟팅을 사용하고 싶다면 오토 타겟팅을, 타겟을 세밀하게 정하고 싶다면 직접 타겟팅을 사용해 주세요.

{% hint style="info" %}
💡 **공통 준수 사항 - 성인 타겟팅**

* 성인 타겟팅은 성인(만 19세 이상)에게만 노출해야 하는 업종이나 광고일 때 사용하는 설정이에요.
* 성인 타겟팅을 사용하면 만 19세 이상에게만 광고가 노출되고, 미성년자(만 14\~18세)에게는 노출되지 않아요.
* 주류·담배·전자담배·데이팅·게임(성인 등급) 등 미성년자 보호 정책에 해당하는 업종·소재는 성인 타겟팅을 반드시 사용해야 해요. 자세한 대상은 [성인 타겟팅 필수 업종·소재](../../review/industryguide.md) 가이드에서 확인할 수 있어요.
* 성인 타겟팅 설정 후 광고 심사를 신청하면 설정을 바꿀 수 없으니, 심사 신청 전에 꼭 확인해 주세요.
{% endhint %}

* **오토 타겟팅**
  * 오토 타겟팅은 토스가 광고에 반응할 가능성이 높은 사용자를 자동으로 찾아 노출하는 방식이에요.
  * 연령·성별 등 세부 타겟을 직접 설정하지 않아도 되고, 기본적으로 전체 연령을 대상으로 해요.
  * 오토 타겟팅은 타겟을 자동으로 탐색하기 때문에, 예상 타겟 수는 미리 확인할 수 없어요.
  * **광고에서 제외할 대상 설정하기**
    * 오토 타겟팅을 사용할 때는, 광고를 노출하고 싶지 않은 대상을 제외할 수 있어요.
    * 연령, 성별, 고객 목록을 기준으로 제외할 수 있어요. (이 기능은 오토 타겟팅에서만 제공해요.)
    * 제외하는 대상이 적을수록 토스가 더 많은 사용자를 탐색할 수 있어, 광고 성과를 높이는 데 도움이 돼요.
* **직접 타겟팅**
  * 광고를 노출할 대상을 직접 설정하는 방식이에요. 데모그래피(성별·디바이스·통신사·연령·지역)와 맞춤 타겟을 조합해 원하는 타겟을 만들 수 있어요.
  * **타겟 조합이란?**
    * 데모그래피 (성별 / 디바이스 / 통신사 / 연령 / 지역)와 맞춤 타겟 혹은 내 타겟을 조합한 타겟이에요.
    * 새 타겟 조합을 통해 처음부터 조건을 설정하여 새로운 타겟을 만들거나, 타겟 조합 가져오기를 통해 기존에 생성해둔 타겟을 불러와서 사용할 수 있어요.
    * 내 타겟 가져오기와 타겟 조합 가져오기는 타겟 페이지에서 만들 수 있어요.
  * **데모그래피**
    * 성별
      * 남성/여성을 타겟팅할 수 있으며, 전체를 클릭하면 성별과 관계 없이 모두를 타겟팅할 수 있어요.
      * 성별은 사용자가 직접 등록한 정보 또는 추정된 정보에 근거하며, 실제와 다를 수 있어요.
    * 디바이스
      * 광고 타겟의 모바일 운영체제를 설정할 수 있으며, Android 혹은 iOS를 선택할 수 있어요. PC 기기에 대해서는 지원하지 않아요.
      * 광고를 본 사용자의 디바이스 정보가 정확하지 않은 경우 디바이스 기반의 타겟팅이 정상적으로 동작하지 않을 수 있어요.
    * 통신사
      * 광고 타겟의 특정 통신사 정보를 설정할 수 있으며, 전체를 클릭하면 통신사 정보와 관계 없이 모두를 타겟팅할 수 있어요.
      * 특정 통신사 정보는 여러 개 동시에 설정할 수 있어요.
    * 연령
      * 만 14\~18세(미성년자)부터 만 나이 기준으로 5\~6세 단위로 설정할 수 있으며, 70세 이상은 '70세 이상'으로 설정할 수 있어요.
      * 단, 성인 타겟팅을 사용하는 경우에는 미성년자(만 14\~18세) 연령을 선택할 수 없어요.
      * 연령은 사용자가 직접 등록한 정보 또는 추정된 정보에 근거하며, 실제와 다를 수 있어요.
    * 지역
      * 광고 타겟의 거주 지역을 설정할 수 있으며, 전체를 클릭하면 지역과 관계 없이 모두를 타겟팅할 수 있어요.
      * 지역 타겟팅은 2단계 (도>시, 특별/광역시>구) 등으로 설정할 수 있으며, 여러 지역을 동시에 설정할 수 있어요.
      * 지역은 사용자가 직접 등록한 정보 또는 추정된 지역 정보에 근거하며 실제와 다를 수 있어요.
  * **맞춤 타겟**
    * 맞춤 타겟을 다른 타겟팅 옵션과 여러 개 사용할 경우, 타겟 모수가 너무 작아져 광고 효과가 감소할 수 있으니 주의해서 사용하시는 것을 권장해요.
    * 업종 카테고리
      * 업종 카테고리는 특정 업종 카테고리에 결제를 했거나 하지 않은 사용자를 찾을 수 있게 해주는 광고 타겟팅 옵션이에요.
      * 3단계 (대 카테고리 > 중 카테고리 > 소 카테고리) 등으로 설정할 수 있으며, 여러 업종을 동시에 설정할 수 있어요.
      * 업종 카테고리 안에서 여러 개의 업종을 선택한 경우, 모든 업종에 대한 합집합(포함)으로만 선택할 수 있어요.
      * 여러 조건의 업종 카테고리 활용 맞춤 타겟을 선택한 경우에도, 모든 조건에 대한 합집합 (포함) 으로 사용돼요.
      * 업종을 선택한 이후에, 상세 타겟 조건 (결제 기간, 결제 금액, 결제 횟수) 을 추가로 선택할 수 있어요.
    * 관심 · 속성 정보
      * 관심 · 속성 정보는 토스 내 특정 서비스 이용 이력을 바탕으로 사용자의 관심사를 유추하여 찾을 수 있게 해주는 광고 타겟팅 옵션이에요.
      * 2단계 (대 카테고리 > 소 카테고리) 로 설정할 수 있으며, 여러 관심사를 동시에 설정할 수 있어요.
    * 소비 수준
      * 소비 수준은 사용자의 최근 월 평균 결제 금액을 기반으로 하여 소비 금액의 분포를 찾을 수 있게 해주는 광고 타겟팅 옵션이에요.
  * **타겟 유의 사항**
    * 광고 유형과 설정한 타겟 조건에 따라 상단 **예상 타겟** 섹션을 통해 해당되는 타겟의 예상 규모를 확인할 수 있어요.
    * 예상 타겟 규모가 50,000명 미만인 경우 광고를 집행할 수 없어요.
    * 예상 타겟 규모가 50,000명 미만으로 조회되는 경우, 타겟 조건을 완화하여 설정해 주세요.
    * 선택한 타겟에게 노출되기까지 최대 1일이 걸릴 수 있어요.
    * 예상 타겟 수는 전체 지면 중 최대값을 기준으로 산정돼요.
    * 실 타겟 수는 설정한 소재와 서비스 상황에 따라 달라질 수 있어요.
    * 타겟 조건 추가 시, 사용자 설정에 따라 타겟 수가 달라질 수 있어요.
    * 설정한 조건의 타겟 수는 시간이 지나 바뀔 수 있어요.
  * **광고 반응 가져오기**
    * 해당 광고계정에서 기존에 집행했던 광고 타겟의 행동 이력을 바탕으로 타겟에서 포함하거나 제외할 수 있는 타겟팅 옵션이에요.
    * 기존 집행한 광고 타겟을 선택하고, 해당 타겟의 상세 행동 (예, 클릭한 유저) 조건을 선택하여 포함하거나 제외할 수 있어요.
    * 광고 반응 타겟은 3개까지 적용 가능하고 동일한 조건의 타겟은 중복 설정할 수 없어요.
  * **전환 추적 가져오기**
    * 상세한 내용은 [전환 추적 타겟](../../targeting/switch.md) 페이지에서 확인할 수 있어요.
    * 전환 추적 타겟은 최대 10개까지 적용 가능해요.
  * **타겟 조합 가져오기**
    * 이전에 만들어둔 타겟 조합을 불러와 사용할 수 있어요.
    * 성인 타겟팅을 사용하는 경우에는, 미성년자가 포함된 타겟 조합은 불러올 수 없고 성인만 포함된 타겟 조합만 선택할 수 있어요.
    * 기존(이전 버전)에 만든 타겟 조합도 불러올 수 있어요. 단, 이 경우 연령은 '10대 제외 전체'로 표시돼요.

**노출 기간, 노출 시간, 소진 방식**

* 노출 기간
  * 광고세트 노출 기간을 설정하실 수 있어요.
  * 캠페인 기간과 동일 옵션을 선택하실 경우 광고세트가 속한 캠페인의 기간과 동일하게 노출이 진행돼요.
  * 광고세트 노출 기간은 캠페인 집행 기간 이내로 설정할 수 있어요.
* 노출 시간
  * 상시 노출 값으로 기본 적용돼요.
  * 노출 시간대 설정을 클릭하실 경우 간단하게 노출 시간대를 설정할 수 있어요.
  * 요일별 시간대 설정을 클릭하실 경우 노출 요일과 시간을 설정할 수 있어요.
* 소진 방식
  * 일반 소진
    * 지정된 노출 시간 동안 노출량이 균등하게 조정되는 방식이에요.
  * 빠른 소진
    * 최대 노출량을 받고 예산을 빠르게 태우는 방식이에요.
  * 소진 방식은 광고 집행 중에도 언제든 변경할 수 있어요.

광고세트까지 설정했다면, [배너 소재 가이드](banner-guide/)에서 소재를 등록하고 [소재별 심사 정책](../../review/creativeguide.md)에 따라 심사를 신청해 주세요. 집행을 시작한 뒤에는 [성과 보기](../performance.md)에서 성과를 확인할 수 있어요.
