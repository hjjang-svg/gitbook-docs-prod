# 잠재고객 모으기

잠재고객 모으기는 질문 양식이나 외부 페이지로 유저를 유도해 **잠재고객을 확보**하는 광고예요. 이 문서를 따라 하면 잠재고객 모으기 캠페인을 만들고, 광고세트까지 설정해 광고를 집행할 준비를 마칠 수 있어요.

## 잠재고객 모으기란? <a href="#lead-generation-overview" id="lead-generation-overview"></a>

잠재고객 모으기는 잠재고객 확보를 목적으로 하는 광고로, 유저가 브릿지 페이지(혜택 소개 화면)에서 정보 입력으로 이어지는 버튼 클릭 시 과금돼요.&#x20;

캠페인을 만들 때 아래 두 등록 방식 중 하나를 선택하며, 등록 방식에 따라 준비물부터 과금·입찰·랜딩까지 달라져요.

* **토스 양식 사용:** 토스 안에서 바로 작성하는 고객 수집 양식으로 고객 정보를 수집해요.
* **URL로 사용:** 알리고 싶은 페이지의 외부 URL로 유저를 보내요.

{% hint style="info" %}
**등록 방식에 따라 사용할 수 있는 소재와 적용 기준이 달라요.**

**토스 양식 사용(네이티브 광고)**: 토스 안에서 고객 수집 양식을 작성해 정보를 수집해요. 한 줄 배너·이미지·비디오 중에서 선택할 수 있어요. [한 줄 배너의 토스 양식 사용 추가 문구 기준 보기](../creative-guidelines/single-line-banner.md#lead-generation-copy)

**URL로 사용**: 알리고 싶은 외부 페이지로 유저를 보내요. 한 줄 배너·이미지·비디오 중에서 선택할 수 있어요. [URL 방식 배너 소재 가이드 보기](banner-guide/)
{% endhint %}

## 광고를 만드는 3단계 구조

토스애즈에서 광고를 집행하려면 **캠페인 > 광고세트 > 소재** 3단계를 등록해야 해요.

| 단계       | 설정하는 것                                     |
| -------- | ------------------------------------------ |
| **캠페인**  | 광고 목표, 집행 기간, 총 예산을 설정하고 하위 광고세트·소재를 관리해요. |
| **광고세트** | 일 예산, 입찰 방식, 타겟, 노출 일정을 설정해요.              |
| **소재**   | 유저에게 실제로 보이는 이미지·문구 등 크리에이티브를 설정해요.        |

{% hint style="info" %}
💡 이 문서에서는 캠페인과 광고세트까지 다뤄요. 소재 단계는 위 콜아웃의 등록 방식별 가이드에서 이어서 확인해 주세요.
{% endhint %}

## 등록 방식 선택하기 <a href="#choose-registration-method" id="choose-registration-method"></a>

두 방식은 준비물과 광고 운영 방식이 서로 달라요. 아래 표에서 차이를 먼저 확인하고, 목적에 맞는 방식으로 이동해 주세요.

| 비교 항목          | **토스 양식 사용**                             | **URL로 사용**                                                   |
| -------------- | ---------------------------------------- | ------------------------------------------------------------- |
| **이런 경우에 좋아요** | 토스 안에서 바로 상담 신청·정보를 받고 싶을 때              | 이미 운영 중인 외부 페이지로 유도하고 싶을 때                                    |
| **과금 시점**      | 브릿지 페이지(혜택 소개 화면)에서 정보 입력으로 이어지는 버튼 클릭 시 | 브릿지 페이지(혜택 소개 화면)에서 정보 입력으로 이어지는 버튼 클릭 또는 광고 배너 소재 클릭 시 (CPC) |
| **입찰 방식**      | 목표 전환당 비용(tCPA)                          | 목표 전환당 비용(tCPA)                                               |
| **타겟팅**        | 오토 타겟팅                                   | 오토 타겟팅                                                        |
| **소재**         | 한 줄 배너·이미지·비디오와 고객 수집 양식을 설정             | 한 줄 배너·이미지·비디오를 직접 등록                                         |
| **랜딩**         | 고객 수집 양식                                 | 브릿지 페이지(혜택 소개 화면) 및 단일 URL(아웃링크)                              |
| **필수 준비물**     | 소개 화면에 넣을 혜택·수집 정보                       | 소개 화면에 넣을 혜택·수집 정보, 전환 및 추적 연동                                |

### 광고세트 만들기 <a href="#toss-form-settings" id="toss-form-settings"></a>

캠페인 하위에 광고세트를 만들어 예산, 입찰, 타겟 조건을 설정해요.

**일 예산**

하루 동안 집행할 예산을 설정해요. 캠페인 총 예산 한도 안에서 설정할 수 있고, 이미 집행된 금액보다 적게는 설정할 수 없어요.

**입찰 방식**

토스 양식 사용은 **목표 전환당 비용(tCPA)** 자동 입찰을 지원해요. 목표로 정한 전환당 비용을 달성하도록, 전환 가능성이 높은 유저에게 자동 입찰해요.

{% hint style="info" %}
**자동 입찰은 학습 시간이 필요해요.**

tCPA는 머신러닝이 전환 데이터를 학습하며 입찰을 최적화하는 방식이라, 최적화까지 최대 일주일 정도 걸릴 수 있어요. 학습 초기에는 비용이 일시적으로 목표보다 높아질 수 있지만, 점차 목표 비용에 가까워져요. 다만 목표 비용이 너무 낮으면 예산이 소진되지 않고 전환도 잘 모이지 않을 수 있으니, 이 경우 목표 비용을 조금 올려보세요.
{% endhint %}



**타겟팅**

토스 양식 사용은 **오토 타겟팅**으로 운영돼요. 토스가 광고에 반응할 가능성이 높은 유저를 자동으로 찾아 노출해요.

* **오토 타겟팅**
  * 오토 타겟팅은 토스가 광고에 반응할 가능성이 높은 사용자를 자동으로 찾아 노출하는 방식이에요.
  * 연령·성별 등 세부 타겟을 직접 설정하지 않아도 되고, 기본적으로 전체 연령을 대상으로 해요.
  * 오토 타겟팅은 타겟을 자동으로 탐색하기 때문에, 예상 타겟 수는 미리 확인할 수 없어요.
  * **광고에서 제외할 대상 설정하기**
    * 오토 타겟팅을 사용할 때는, 광고를 노출하고 싶지 않은 대상을 제외할 수 있어요.
    * 연령, 성별, 고객 목록, OS를 기준으로 제외할 수 있어요. (이 기능은 오토 타겟팅에서만 제공해요.)
    * 제외하는 대상이 적을수록 토스가 더 많은 사용자를 탐색할 수 있어, 광고 성과를 높이는 데 도움이 돼요.

{% hint style="info" %}
**공통 준수 사항 - 성인 타겟팅**

* 성인 타겟팅은 성인(만 19세 이상)에게만 노출해야 하는 업종이나 광고일 때 사용하는 설정이에요.
* 성인 타겟팅을 사용하면 만 19세 이상에게만 광고가 노출되고, 미성년자(만 14\~18세)에게는 노출되지 않아요.
* 주류·담배·전자담배·데이팅·게임(성인 등급) 등 미성년자 보호 정책에 해당하는 업종·소재는 성인 타겟팅을 반드시 사용해야 해요. 자세한 대상은 [성인 타겟팅 필수 업종·소재](../../review/industryguide.md) 가이드에서 확인할 수 있어요.
* 성인 타겟팅 설정 후 광고 심사를 신청하면 설정을 바꿀 수 없으니, 심사 신청 전에 꼭 확인해 주세요.
{% endhint %}

**노출 기간, 노출 시간**

* 노출 기간
  * 광고세트 노출 기간을 설정하실 수 있어요.
  * 캠페인 기간과 동일 옵션을 선택하실 경우 광고세트가 속한 캠페인의 기간과 동일하게 노출이 진행돼요.
  * 광고세트 노출 기간은 캠페인 집행 기간 이내로 설정할 수 있어요.
* 노출 시간
  * 상시 노출 값으로 기본 적용돼요.
  * 노출 시간대 설정을 클릭하실 경우 간단하게 노출 시간대를 설정할 수 있어요.
  * 요일별 시간대 설정을 클릭하실 경우 노출 요일과 시간을 설정할 수 있어요.

광고세트까지 설정했다면, [잠재고객 모으기 양식 가이드](creative.md)에서 고객 수집 양식을 만들고 [네이티브 광고 전용 문구 기준](../creative-guidelines/single-line-banner.md#lead-generation-copy)에 따라 한 줄 배너를 등록한 뒤, [소재별 심사 정책](../../review/creativeguide.md)에 따라 심사를 신청해 주세요. 집행을 시작한 뒤에는 [성과 보기](../performance.md)에서 성과를 확인할 수 있어요.

토스 양식 사용은 **오토 타겟팅**으로 운영돼요. 토스가 광고에 반응할 가능성이 높은 유저를 자동으로 찾아 노출해요.

* **오토 타겟팅**
  * 오토 타겟팅은 토스가 광고에 반응할 가능성이 높은 사용자를 자동으로 찾아 노출하는 방식이에요.
  * 연령·성별 등 세부 타겟을 직접 설정하지 않아도 되고, 기본적으로 전체 연령을 대상으로 해요.
  * 오토 타겟팅은 타겟을 자동으로 탐색하기 때문에, 예상 타겟 수는 미리 확인할 수 없어요.
  * **광고에서 제외할 대상 설정하기**
    * 오토 타겟팅을 사용할 때는, 광고를 노출하고 싶지 않은 대상을 제외할 수 있어요.
    * 연령, 성별, 고객 목록, OS를 기준으로 제외할 수 있어요. (이 기능은 오토 타겟팅에서만 제공해요.)
    * 제외하는 대상이 적을수록 토스가 더 많은 사용자를 탐색할 수 있어, 광고 성과를 높이는 데 도움이 돼요.

{% hint style="info" %}
**공통 준수 사항 - 성인 타겟팅**

* 성인 타겟팅은 성인(만 19세 이상)에게만 노출해야 하는 업종이나 광고일 때 사용하는 설정이에요.
* 성인 타겟팅을 사용하면 만 19세 이상에게만 광고가 노출되고, 미성년자(만 14\~18세)에게는 노출되지 않아요.
* 주류·담배·전자담배·데이팅·게임(성인 등급) 등 미성년자 보호 정책에 해당하는 업종·소재는 성인 타겟팅을 반드시 사용해야 해요. 자세한 대상은 [성인 타겟팅 필수 업종·소재](../../review/industryguide.md) 가이드에서 확인할 수 있어요.
* 성인 타겟팅 설정 후 광고 심사를 신청하면 설정을 바꿀 수 없으니, 심사 신청 전에 꼭 확인해 주세요.
{% endhint %}

**노출 기간, 노출 시간, 소진 방식**

* 노출 기간
  * 광고세트 노출 기간을 설정하실 수 있어요.
  * 캠페인 기간과 동일 옵션을 선택하실 경우 광고세트가 속한 캠페인의 기간과 동일하게 노출이 진행돼요.
  * 광고세트 노출 기간은 캠페인 집행 기간 이내로 설정할 수 있어요.
* 노출 시간
  * 상시 노출 값으로 기본 적용돼요.
  * 노출 시간대 설정을 클릭하실 경우 간단하게 노출 시간대를 설정할 수 있어요.
  * 요일별 시간대 설정을 클릭하실 경우 노출 요일과 시간을 설정할 수 있어요.

광고세트까지 설정했다면, [배너 소재 가이드](banner-guide/)에서 소재를 등록하고 [소재별 심사 정책](../../review/creativeguide.md)에 따라 심사를 신청해 주세요. 집행을 시작한 뒤에는 [성과 보기](../performance.md)에서 성과를 확인할 수 있어요.
