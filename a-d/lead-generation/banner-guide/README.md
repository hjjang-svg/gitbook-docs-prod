# 배너 소재 가이드

캠페인에서 선택한 등록 방식에 따라 등록할 수 있는 소재 유형과 적용 기준이 달라요. 등록 방식을 확인한 뒤 사용할 수 있는 소재 가이드를 확인해 주세요.

| 등록 방식                 | 등록할 수 있는 소재 유형 |
| --------------------- | -------------- |
| **토스 양식 사용(네이티브 광고)** | 한 줄 배너만        |
| **URL로 사용**           | 한 줄 배너·이미지·비디오 |

등록하려는 소재 유형에 맞는 가이드를 확인해 주세요.
