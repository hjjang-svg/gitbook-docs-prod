# 구매 유도하기

구매 유도하기는 상품이나 혜택을 노출해 유저의 **구매 전환**을 이끌어내는 퍼포먼스 광고예요. 이 문서를 따라 하면 구매 유도하기 캠페인을 만들고, 광고세트까지 설정해 광고를 집행할 준비를 마칠 수 있어요.

## 구매 유도하기란? <a href="#purchase-overview" id="purchase-overview"></a>

구매 유도하기는 구매 전환을 목적으로 하는 광고예요. 캠페인을 만들 때 광고를 등록하는 방식을 두 가지 중에서 고를 수 있고, 어떤 방식을 고르느냐에 따라 준비물부터 과금·입찰·노출 지면까지 달라져요.

* **카탈로그 연동(토스 네이티브 광고):** 여러 상품을 담은 카탈로그를 연동하면, 관심사에 맞는 고객에게 상품이 카드 형태로 자동 노출돼요. 상품 수가 많고, 고객마다 맞는 상품을 자동으로 보여주고 싶을 때 적합해요.
* **직접 등록:** 알리고 싶은 상품이나 혜택을 한 줄 배너·이미지·비디오 형태로 직접 만들어 등록해요. 단일 상품이나 프로모션을 원하는 소재로 알리고 싶을 때 적합해요.

### 광고를 만드는 3단계 구조

토스애즈에서 광고를 집행하려면 **캠페인 > 광고세트 > 소재** 3단계를 등록해야 해요.

| 단계       | 설정하는 것                                     |
| -------- | ------------------------------------------ |
| **캠페인**  | 광고 목표, 집행 기간, 총 예산을 설정하고 하위 광고세트·소재를 관리해요. |
| **광고세트** | 일 예산, 입찰 방식, 타겟, 노출 일정을 설정해요.              |
| **소재**   | 유저에게 실제로 보이는 이미지·문구 등 크리에이티브를 설정해요.        |

{% hint style="info" %}
💡 소재는 등록 방식에 따라 다르게 만들어요. 카탈로그 연동 방식은 [카탈로그 소재 가이드](creative.md)에서, 직접 등록 방식은 [배너 소재 가이드](../creative-guidelines/)에서 확인할 수 있어요. 이 문서에서는 캠페인과 광고세트까지 다뤄요.
{% endhint %}

## 등록 방식 선택하기 <a href="#choose-registration-method" id="choose-registration-method"></a>

두 방식은 준비물과 광고 운영 방식이 서로 달라요. 아래 표에서 차이를 먼저 확인하고, 목적에 맞는 방식으로 이동해 주세요.

| 비교 항목          | 직접 등록                    | 카탈로그 연동(토스 네이티브 광고)                     |
| -------------- | ------------------------ | --------------------------------------- |
| **이런 경우에 좋아요** | 단일 상품·혜택을 직접 만든 소재로 알릴 때 | 커머스 상품이 많고, 고객별 맞춤 상품을 자동 노출하고 싶을 때     |
| **과금 시점**      | 광고 배너 소재 클릭 시 (CPC)      | 브릿지 페이지(상품 소개 화면)에서 광고주 아웃링크로 이동하는 클릭 시 |
| **입찰 방식**      | 자동 입찰(전환 최대)·직접 입찰(CPC)  | 목표 광고 수익률(tROAS)                        |
| **타겟팅**        | 오토 타겟팅·직접 타겟팅            | 오토 타겟팅                                  |
| **소재**         | 문구·이미지·비디오를 직접 등록        | 카탈로그 상품이 카드로 자동 노출                      |
| **랜딩**         | 단일 URL(아웃링크)             | 카탈로그의 상품별 URL                           |
| **필수 준비물**     | 전환 및 추적 연동               | 전환 및 추적 연동, 상품 카탈로그                     |

## 카탈로그 연동으로 광고 만들기 <a href="#catalog-flow" id="catalog-flow"></a>

### 시작하기 전 준비하기 <a href="#catalog-prerequisites" id="catalog-prerequisites"></a>

카탈로그 연동 광고는 **상품 카탈로그**가 준비돼 있어야 만들 수 있어요.

**상품 카탈로그를 준비해주세요.**

광고할 상품 목록을 카탈로그로 등록하고, 광고에 사용할 상품 세트까지 준비해야 해요. 카탈로그를 만들고 상품을 등록하는 방법은 [카탈로그 연동하기](../../catalog/how-to.md) 가이드에서 안내하고 있어요. 상품 데이터 형식은 [카탈로그 연동 스펙](../../catalog/spec.md), 광고 제한 기준은 [카탈로그 심사 정책](../../review/catalog.md)에서 확인할 수 있어요.

**전환 및 추적 연동을 완료해주세요.**

카탈로그를 활용한 구매 유도하기는 전환 및 추적 연동이 필수예요.

{% hint style="info" %}
💡 캠페인을 만들기 전에 **집행 가능한 상품이 담긴 상품 세트**가 준비됐는지 꼭 확인해주세요. 상품이 0개인 상품 세트는 광고에 연결할 수 없어요.
{% endhint %}

### 캠페인 만들기 <a href="#catalog-create-campaign" id="catalog-create-campaign"></a>

1. 좌측 메뉴에서 **캠페인 생성**을 눌러주세요.
2. 캠페인 목표에서 **구매 유도하기**를 선택해주세요.
3. 광고 등록 방식에서 **카탈로그 연동**을 선택해주세요.
4. 캠페인 정보를 입력해주세요. 입력 항목은 직접 등록과 같아요.

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2FxsSb0Vum6nQ5n4y4avea%2Fclipboard.png?alt=media&#x26;token=24a9c580-a67e-4f9f-9797-72e25c0aaf6f" alt="광고 등록 방식에서 카탈로그 연동과 직접 등록을 확인하는 화면"><figcaption></figcaption></figure>

| 입력 항목          | 안내                                                    |
| -------------- | ----------------------------------------------------- |
| **캠페인명**       | 관리하기 쉬운 이름으로 입력해주세요. 입력하지 않으면 `캠페인_생성일시`로 자동 저장돼요.    |
| **총 예산**       | 캠페인 집행 기간 동안 쓸 예산 한도예요. 100,000원 이상, 100원 단위로 입력해주세요. |
| **집행 기간**      | 광고가 노출되는 전체 기간이에요. 종료일을 두지 않으려면 **종료일 없음**을 선택해주세요.   |
| **카탈로그 연동**    | 연동할 카탈로그를 선택해주세요.                                     |
| **전환 및 추적 연동** | 연동을 마친 전환 추적 코드를 선택해주세요.                              |

{% hint style="info" %}
💡 캠페인에 연결한 **카탈로그와 상품 세트는 심사 제출 이후 변경할 수 없어요.** 제출 전에 연결을 다시 확인해주세요.
{% endhint %}

### 광고세트 만들기 <a href="#catalog-settings" id="catalog-settings"></a>

**상품 세트 연결**

광고세트마다 상품 세트 하나를 반드시 연결해요. 이 광고세트로 노출할 상품이 담긴 상품 세트를 선택해주세요.

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2FJpoFaQPqDv94x6sPv3OV%2Fclipboard.png?alt=media&#x26;token=d775ab22-e3a8-476a-bad8-4f35e5bbd207" alt="카탈로그 광고세트에서 상품 세트를 연결하는 화면"><figcaption></figcaption></figure>

**일 예산**

하루 동안 집행할 예산을 설정해요. 캠페인 총 예산 한도 안에서 설정할 수 있고, 이미 집행된 금액보다 적게는 설정할 수 없어요.

**입찰 방식**

카탈로그 연동은 **목표 광고 수익률(Target ROAS)** 자동 입찰을 지원해요. 설정한 광고수익률을 목표로 입찰 금액을 자동으로 최적화하는 전략이에요.

{% hint style="info" %}
💡 **자동 입찰은 학습 시간이 필요해요.** Target ROAS는 머신러닝이 전환 데이터를 학습하며 입찰을 최적화하는 방식이라, 최적화까지 최대 일주일 정도 걸릴 수 있어요. 학습 초기에는 비용이 일시적으로 목표보다 높아질 수 있지만, 점차 목표 비용에 가까워져요. 다만 목표 비용이 너무 낮으면 예산이 소진되지 않고 전환도 잘 모이지 않을 수 있으니, 이 경우 목표 비용을 조금 올려보세요.
{% endhint %}

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2FCiL1Qv7b5zjTLqpDCxzz%2Fpurchase-bid-20260727.png?alt=media&#x26;token=ea928a7f-2b24-4279-a88e-3db0f6f31bfe" alt="카탈로그 연동 광고세트에서 목표 광고 수익률을 설정하는 화면"><figcaption></figcaption></figure>

**타겟팅**

카탈로그 연동은 **오토 타겟팅**으로 운영돼요. 토스가 상품에 관심 가질 가능성이 높은 유저를 자동으로 찾아 노출해요.

* **오토 타겟팅**
  * 오토 타겟팅은 토스가 광고에 반응할 가능성이 높은 사용자를 자동으로 찾아 노출하는 방식이에요.
  * 연령·성별 등 세부 타겟을 직접 설정하지 않아도 되고, 기본적으로 전체 연령을 대상으로 해요.
  * 오토 타겟팅은 타겟을 자동으로 탐색하기 때문에, 예상 타겟 수는 미리 확인할 수 없어요.
  * **광고에서 제외할 대상 설정하기**
    * 오토 타겟팅을 사용할 때는, 광고를 노출하고 싶지 않은 대상을 제외할 수 있어요.
    * 연령, 성별, 고객 목록을 기준으로 제외할 수 있어요. (이 기능은 오토 타겟팅에서만 제공해요.)
    * 제외하는 대상이 적을수록 토스가 더 많은 사용자를 탐색할 수 있어, 광고 성과를 높이는 데 도움이 돼요.

{% hint style="info" %}
💡 **공통 준수 사항 - 성인 타겟팅**

* 성인 타겟팅은 성인(만 19세 이상)에게만 노출해야 하는 업종이나 광고일 때 사용하는 설정이에요.
* 성인 타겟팅을 사용하면 만 19세 이상에게만 광고가 노출되고, 미성년자(만 14\~18세)에게는 노출되지 않아요.
* 주류·담배·전자담배·데이팅·게임(성인 등급) 등 미성년자 보호 정책에 해당하는 업종·소재는 성인 타겟팅을 반드시 사용해야 해요. 자세한 대상은 [성인 타겟팅 필수 업종·소재](../../review/industryguide.md) 가이드에서 확인할 수 있어요.
* 성인 타겟팅 설정 후 광고 심사를 신청하면 설정을 바꿀 수 없으니, 심사 신청 전에 꼭 확인해 주세요.
{% endhint %}

**노출 기간, 노출 시간**

* 노출 기간
  * 광고세트 노출 기간을 설정하실 수 있어요.
  * 캠페인 기간과 동일 옵션을 선택하실 경우 광고세트가 속한 캠페인의 기간과 동일하게 노출이 진행돼요.
  * 광고세트 노출 기간은 캠페인 집행 기간 이내로 설정할 수 있어요.
* 노출 시간
  * 상시 노출 값으로 기본 적용돼요.
  * 노출 시간대 설정을 클릭하실 경우 간단하게 노출 시간대를 설정할 수 있어요.
  * 요일별 시간대 설정을 클릭하실 경우 노출 요일과 시간을 설정할 수 있어요.

광고세트까지 설정했다면, [구매 유도하기 소재 가이드](creative.md)에서 상품 세트와 소재를 확인하고 [소재별 심사 정책](../../review/creativeguide.md)에 따라 심사를 신청해 주세요. 집행을 시작한 뒤에는 [성과 보기](../performance.md)에서 성과를 확인할 수 있어요. 카탈로그 광고의 소재는 상품 정보 기반으로 자동 구성돼요.

***

## 직접 등록으로 광고 만들기 <a href="#direct-flow" id="direct-flow"></a>

### 시작하기 전 준비하기 <a href="#direct-prerequisites" id="direct-prerequisites"></a>

* **전환 및 추적 연동을 완료해주세요.**
  * 구매 유도하기는 성과를 정확히 측정하기 위해 전환 및 추적 연동이 필수예요. 광고 랜딩이 웹이라면 [웹 광고 성과 측정 연동(토스 픽셀)](../../tracking/tosspixel/)을, 앱이라면 앱 성과 측정 도구(MMP)를 이용하는 [앱 광고 성과 측정 연동(MAT)](../../tracking/mat/)을 먼저 완료해주세요.
* **미리 준비할 정보**
  * 광고를 클릭했을 때 이동할 **전환 추적이 가능한 랜딩 URL**
  * 소재에 사용할 문구·이미지·영상

### 캠페인 만들기 <a href="#direct-create-campaign" id="direct-create-campaign"></a>

1. 좌측 메뉴에서 **캠페인 생성**을 눌러주세요.
2. 캠페인 목표에서 **구매 유도하기**를 선택해주세요.
3. 광고 등록 방식에서 **직접 등록**을 선택해주세요.
4. 아래 캠페인 정보를 입력해주세요.

| 입력 항목          | 안내                                                    |
| -------------- | ----------------------------------------------------- |
| **캠페인명**       | 관리하기 쉬운 이름으로 입력해주세요. 입력하지 않으면 `캠페인_생성일시`로 자동 저장돼요.    |
| **총 예산**       | 캠페인 집행 기간 동안 쓸 예산 한도예요. 100,000원 이상, 100원 단위로 입력해주세요. |
| **집행 기간**      | 광고가 노출되는 전체 기간이에요. 종료일을 두지 않으려면 **종료일 없음**을 선택해주세요.   |
| **전환 및 추적 연동** | 연동을 마친 전환 추적 코드를 선택해주세요.                              |

{% hint style="info" %}
💡 전환 및 추적 연동은 **집행을 시작한 뒤에는 변경할 수 없어요.** 캠페인을 만들기 전에 연동을 먼저 마쳐주세요.
{% endhint %}

### 광고세트 만들기 <a href="#direct-settings" id="direct-settings"></a>

캠페인 하위에 광고세트를 만들어 예산, 입찰, 타겟, 노출 조건을 설정해요.

**일 예산**

하루 동안 집행할 예산을 설정해요. 캠페인 총 예산 한도 안에서 설정할 수 있고, 이미 집행된 금액보다 적게는 설정할 수 없어요.

**입찰 방식**

구매 유도하기에서는 아래 입찰 방식을 지원해요.

| 입찰 방식             | 동작 방식                                                         |
| ----------------- | ------------------------------------------------------------- |
| **자동 입찰 · 전환 최대** | 일 예산을 최대한 소진하면서 전환을 가장 많이 얻도록 시스템이 자동으로 입찰해요.                 |
| **직접 입찰(CPC)**    | 클릭당 단가를 직접 설정해요. 설정한 값은 최대 비용이고, 경쟁 상황에 따라 실제 과금은 더 적을 수 있어요. |

{% hint style="info" %}
💡 **자동 입찰은 학습 시간이 필요해요.**\
자동 입찰 · 전환 최대는 머신러닝이 전환 데이터를 학습하며 입찰을 최적화하는 방식이라, 최적화까지 최대 일주일 정도 걸릴 수 있어요. 학습 초기에는 비용이 일시적으로 목표보다 높아질 수 있지만, 점차 목표 비용에 가까워져요. 다만 목표 비용이 너무 낮으면 예산이 소진되지 않고 전환도 잘 모이지 않을 수 있으니, 이 경우 목표 비용을 조금 올려보세요.
{% endhint %}

**타겟팅**

광고 타겟을 **오토 타겟팅**과 **직접 타겟팅** 중에서 선택해 설정해요. 최적화된 자동 타겟팅을 사용하고 싶다면 오토 타겟팅을, 타겟을 세밀하게 정하고 싶다면 직접 타겟팅을 사용해주세요.

{% hint style="info" %}
💡 **공통 준수 사항 - 성인 타겟팅**

* 성인 타겟팅은 성인(만 19세 이상)에게만 노출해야 하는 업종이나 광고일 때 사용하는 설정이에요.
* 성인 타겟팅을 사용하면 만 19세 이상에게만 광고가 노출되고, 미성년자(만 14\~18세)에게는 노출되지 않아요.
* 주류·담배·전자담배·데이팅·게임(성인 등급) 등 미성년자 보호 정책에 해당하는 업종·소재는 성인 타겟팅을 반드시 사용해야 해요. 자세한 대상은 [성인 타겟팅 필수 업종·소재](../../review/industryguide.md) 가이드에서 확인할 수 있어요.
* 성인 타겟팅 설정 후 광고 심사를 신청하면 설정을 바꿀 수 없으니, 심사 신청 전에 꼭 확인해 주세요.
{% endhint %}

* **오토 타겟팅**
  * 오토 타겟팅은 토스가 광고에 반응할 가능성이 높은 사용자를 자동으로 찾아 노출하는 방식이에요.
  * 연령·성별 등 세부 타겟을 직접 설정하지 않아도 되고, 기본적으로 전체 연령을 대상으로 해요.
  * 오토 타겟팅은 타겟을 자동으로 탐색하기 때문에, 예상 타겟 수는 미리 확인할 수 없어요.
  * **광고에서 제외할 대상 설정하기**
    * 오토 타겟팅을 사용할 때는, 광고를 노출하고 싶지 않은 대상을 제외할 수 있어요.
    * 연령, 성별, 고객 목록을 기준으로 제외할 수 있어요. (이 기능은 오토 타겟팅에서만 제공해요.)
    * 제외하는 대상이 적을수록 토스가 더 많은 사용자를 탐색할 수 있어, 광고 성과를 높이는 데 도움이 돼요.
* **직접 타겟팅**
  * 광고를 노출할 대상을 직접 설정하는 방식이에요. 데모그래피(성별·디바이스·통신사·연령·지역)와 맞춤 타겟을 조합해 원하는 타겟을 만들 수 있어요.
  * **타겟 조합이란?**
    * 데모그래피 (성별 / 디바이스 / 통신사 / 연령 / 지역)와 맞춤 타겟 혹은 내 타겟을 조합한 타겟이에요.
    * 새 타겟 조합을 통해 처음부터 조건을 설정하여 새로운 타겟을 만들거나, 타겟 조합 가져오기를 통해 기존에 생성해둔 타겟을 불러와서 사용할 수 있어요.
    * 내 타겟 가져오기와 타겟 조합 가져오기는 타겟 페이지에서 만들 수 있어요.
  * **데모그래피**
    * 성별
      * 남성/여성을 타겟팅할 수 있으며, 전체를 클릭하면 성별과 관계 없이 모두를 타겟팅할 수 있어요.
      * 성별은 사용자가 직접 등록한 정보 또는 추정된 정보에 근거하며, 실제와 다를 수 있어요.
    * 디바이스
      * 광고 타겟의 모바일 운영체제를 설정할 수 있으며, Android 혹은 iOS를 선택할 수 있어요. PC 기기에 대해서는 지원하지 않아요.
      * 광고를 본 사용자의 디바이스 정보가 정확하지 않은 경우 디바이스 기반의 타겟팅이 정상적으로 동작하지 않을 수 있어요.
    * 통신사
      * 광고 타겟의 특정 통신사 정보를 설정할 수 있으며, 전체를 클릭하면 통신사 정보와 관계 없이 모두를 타겟팅할 수 있어요.
      * 특정 통신사 정보는 여러 개 동시에 설정할 수 있어요.
    * 연령
      * 만 14\~18세(미성년자)부터 만 나이 기준으로 5\~6세 단위로 설정할 수 있으며, 70세 이상은 '70세 이상'으로 설정할 수 있어요.
      * 단, 성인 타겟팅을 사용하는 경우에는 미성년자(만 14\~18세) 연령을 선택할 수 없어요.
      * 연령은 사용자가 직접 등록한 정보 또는 추정된 정보에 근거하며, 실제와 다를 수 있어요.
    * 지역
      * 광고 타겟의 거주 지역을 설정할 수 있으며, 전체를 클릭하면 지역과 관계 없이 모두를 타겟팅할 수 있어요.
      * 지역 타겟팅은 2단계 (도>시, 특별/광역시>구) 등으로 설정할 수 있으며, 여러 지역을 동시에 설정할 수 있어요.
      * 지역은 사용자가 직접 등록한 정보 또는 추정된 지역 정보에 근거하며 실제와 다를 수 있어요.
  * **타겟 정보 설정하기**
    * **맞춤 타겟**
    * 맞춤 타겟을 다른 타겟팅 옵션과 여러 개 사용할 경우, 타겟 모수가 너무 작아져 광고 효과가 감소할 수 있으니 주의해서 사용하시는 것을 권장해요.
    * 업종 카테고리
      * 업종 카테고리는 특정 업종 카테고리에 결제를 했거나 하지 않은 사용자를 찾을 수 있게 해주는 광고 타겟팅 옵션이에요.
      * 3단계 (대 카테고리 > 중 카테고리 > 소 카테고리) 등으로 설정할 수 있으며, 여러 업종을 동시에 설정할 수 있어요.
      * 업종 카테고리 안에서 여러 개의 업종을 선택한 경우, 모든 업종에 대한 합집합(포함)으로만 선택할 수 있어요.
      * 여러 조건의 업종 카테고리 활용 맞춤 타겟을 선택한 경우에도, 모든 조건에 대한 합집합 (포함) 으로 사용돼요.
      * 업종을 선택한 이후에, 상세 타겟 조건 (결제 기간, 결제 금액, 결제 횟수) 을 추가로 선택할 수 있어요.
    * 관심 · 속성 정보
      * 관심 · 속성 정보는 토스 내 특정 서비스 이용 이력을 바탕으로 사용자의 관심사를 유추하여 찾을 수 있게 해주는 광고 타겟팅 옵션이에요.
      * 2단계 (대 카테고리 > 소 카테고리) 로 설정할 수 있으며, 여러 관심사를 동시에 설정할 수 있어요.
    * 소비 수준
      * 소비 수준은 사용자의 최근 월 평균 결제 금액을 기반으로 하여 소비 금액의 분포를 찾을 수 있게 해주는 광고 타겟팅 옵션이에요.
  * **타겟 유의 사항**
    * 광고 유형과 설정한 타겟 조건에 따라 상단 **예상 타겟** 섹션을 통해 해당되는 타겟의 예상 규모를 확인할 수 있어요.
    * 예상 타겟 규모가 50,000명 미만인 경우 광고를 집행할 수 없어요.
    * 예상 타겟 규모가 50,000명 미만으로 조회되는 경우, 타겟 조건을 완화하여 설정해 주세요.
    * 선택한 타겟에게 노출되기까지 최대 1일이 걸릴 수 있어요.
    * 예상 타겟 수는 전체 지면 중 최대값을 기준으로 산정돼요.
    * 실 타겟 수는 설정한 소재와 서비스 상황에 따라 달라질 수 있어요.
    * 타겟 조건 추가 시, 사용자 설정에 따라 타겟 수가 달라질 수 있어요.
    * 설정한 조건의 타겟 수는 시간이 지나 바뀔 수 있어요.
  * **광고 반응 가져오기**
    * 해당 광고계정에서 기존에 집행했던 광고 타겟의 행동 이력을 바탕으로 타겟에서 포함하거나 제외할 수 있는 타겟팅 옵션이에요.
    * 기존 집행한 광고 타겟을 선택하고, 해당 타겟의 상세 행동 (예, 클릭한 유저) 조건을 선택하여 포함하거나 제외할 수 있어요.
    * 광고 반응 타겟은 3개까지 적용 가능하고 동일한 조건의 타겟은 중복 설정할 수 없어요.
  * **전환 추적 가져오기**
    * 상세한 내용은 [전환 추적 타겟](../../targeting/switch.md) 페이지에서 확인할 수 있어요.
    * 전환 추적 타겟은 최대 10개까지 적용 가능해요.
  * **타겟 조합 가져오기**
    * 이전에 만들어둔 타겟 조합을 불러와 사용할 수 있어요.
    * 성인 타겟팅을 사용하는 경우에는, 미성년자가 포함된 타겟 조합은 불러올 수 없고 성인만 포함된 타겟 조합만 선택할 수 있어요.
    * 기존(이전 버전)에 만든 타겟 조합도 불러올 수 있어요. 단, 이 경우 연령은 '10대 제외 전체'로 표시돼요.

**노출 기간, 노출 시간, 소진 방식**

* 노출 기간
  * 광고세트 노출 기간을 설정하실 수 있어요.
  * 캠페인 기간과 동일 옵션을 선택하실 경우 광고세트가 속한 캠페인의 기간과 동일하게 노출이 진행돼요.
  * 광고세트 노출 기간은 캠페인 집행 기간 이내로 설정할 수 있어요.
* 노출 시간
  * 상시 노출 값으로 기본 적용돼요.
  * 노출 시간대 설정을 클릭하실 경우 간단하게 노출 시간대를 설정할 수 있어요.
  * 요일별 시간대 설정을 클릭하실 경우 노출 요일과 시간을 설정할 수 있어요.
* 소진 방식
  * 일반 소진
    * 지정된 노출 시간 동안 노출량이 균등하게 조정되는 방식이에요.
  * 빠른 소진
    * 최대 노출량을 받고 예산을 빠르게 태우는 방식이에요.
  * 소진 방식은 광고 집행 중에도 언제든 변경할 수 있어요.

광고세트까지 설정했다면, [배너 소재 가이드](../creative-guidelines/)에서 소재를 등록하고 [소재별 심사 정책](../../review/creativeguide.md)에 따라 심사를 신청해 주세요. 집행을 시작한 뒤에는 [성과 보기](../performance.md)에서 성과를 확인할 수 있어요.
