# 한 줄 배너

## 한 줄 배너란? <a href="#single-line-banner-overview" id="single-line-banner-overview"></a>

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2FR7V5wo2OVkOqquOLaReu%2F1.%20%E1%84%92%E1%85%A1%E1%86%AB%E1%84%8C%E1%85%AE%E1%86%AF%20%E1%84%87%E1%85%A2%E1%84%82%E1%85%A5%E1%84%85%E1%85%A1%E1%86%AB_%20(1).png?alt=media&#x26;token=7e6cfe83-1428-4233-af49-806abdc8e2a8" alt=""><figcaption></figcaption></figure>

가로로 긴 띠 형태의 배너를 뜻해요. 작은 1:1 이미지와 문구로 이루어져 있어요.

잠재고객 모으기 캠페인에서 [토스 양식 사용(네이티브 광고)](../lead-generation/#choose-registration-method)을 선택하면 한 줄 배너의 문구 작성 기준과 문구 규격에 더해 전용 문구 기준이 추가로 적용돼요. 아래 [토스 양식 사용(네이티브 광고) 추가 문구 기준](single-line-banner.md#lead-generation-copy)을 함께 확인해 주세요.

{% hint style="warning" %}
잠재고객 모으기 캠페인에는 소개 화면이 반드시 필요해요. 소개 화면이 없으면 소재 심사에서 반려돼요.
{% endhint %}

## 광고 이미지 <a href="#image" id="image"></a>

## 문구 <a href="#copy" id="copy"></a>

문구를 작성하기 전에 **문구 규격**과 **작성 기준** 탭을 모두 확인해 주세요.

### 잠재고객 모으기 캠페인(토스 양식 사용) 문구 기준 <a href="#lead-generation-copy" id="lead-generation-copy"></a>

[잠재고객 모으기 캠페인](../lead-generation/)에서 **토스 양식 사용(네이티브 광고)**&#xC744; 선택하면 배너에 아래 문구 작성 기준이 추가로 적용돼요. 유저가 배너만 보고도 **‘신청하면 무엇을 얻는지’** 알 수 있어야 해요.

{% hint style="info" %}
[**토스 양식 사용(네이티브 광고)**](../lead-generation/#toss-form-flow): 아래에서 설명하는 추가 문구 기준을 적용해요.

[**URL로 사용**](../lead-generation/#url-flow): 이 전용 문구 기준은 적용하지 않고, 위의 문구 작성 기준과 문구 규격을 따라 주세요.
{% endhint %}

**작성 기준**

<table><thead><tr><th width="134.8125">구분</th><th width="250.83984375">작성 방법</th><th>예시</th></tr></thead><tbody><tr><td><strong>주요 문구</strong></td><td>유저가 할 행동을 <code>~고</code> 형태로 마무리해요.</td><td><strong>가전 구독하고</strong></td></tr><tr><td><strong>보조 문구</strong></td><td>행동으로 얻는 가치나 혜택을 <code>~기</code> 형태로 마무리해요.</td><td><strong>10만원 리워드 받기</strong></td></tr></tbody></table>

상품권·리워드·쿠폰 같은 현물성 혜택이 없어도 캠페인을 집행할 수 있어요.

다만 혜택이 없다면 유저가 행동할 이유가 명확히 보이도록, 제공하는 **서비스 자체의 가치**가 문구에 드러나야 해요.
