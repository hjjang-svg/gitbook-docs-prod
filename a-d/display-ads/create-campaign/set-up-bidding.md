# 입찰 방식 설정하기

### 1. 입찰 방식 한눈에 보기

| 캠페인 목적      | 입찰 방식                                  |
| ----------- | -------------------------------------- |
| 방문 유도하기     | 자동 입찰 클릭 최대, 직접 입찰 CPC                 |
| 10대 인지도 높이기 | 자동 입찰 클릭 최대, 직접 입찰 CPC                 |
| 도달률 높이기     | 직접 입찰 CPM                              |
| 잠재고객 모으기    | 자동 입찰 전환 최대 (목표 비용 tCPA 지원), 직접 입찰 CPC |
| (구매 유도하기)   | 자동 입찰 전환 최대, 직접 입찰 CPC                 |
| (앱 설치 유도하기) | 자동 입찰 전환 최대, 직접 입찰 CPC                 |

### 2. 입찰 방식 자세히 보기

#### 자동 입찰 클릭 최대

* 클릭을 최대화하기 위해 주어진 일 예산을 최대한 소진하면서도 가장 효율적인 CPC(클릭당 단가)를 얻기 위해 토스가 자동으로 입찰을 결정해요.
* 자동 입찰 클릭 최대화를 선택하여 운영하는 경우 소진 방식도 시스템이 자동으로 운영해요.
  * \[일반 소진] , \[빠른 소진] 옵션은 선택 및 적용이 불가해요.
* 캠페인 집행중에는 입찰 방식을 아래 조건에 따라 바꿀 수 있어요.
  * 광고세트 생성 후에는 \[클릭 최대화 / 직접 입찰 CPC] <> \[CPM] 사이에 입찰방식 변경이 불가해요.
  * \[자동 입찰 클릭 최대화] <> \[직접 입찰 CPC] 사이의 입찰방식 변경은 언제든 변경 가능해요.
* 운영 유의사항
  * 광고세트를 켜는 시간이 설정된 시간 타겟팅보다 늦으면, 캠페인 운영 첫날에는 예산이 모두 소진되지 않을 수 있어요. 첫날부터 예산을 모두 소진하고 싶다면 시간 타겟팅 이전에 미리 광고세트를 ON 해주세요.
  * 일 예산, 타겟 세그먼트, 시간 타겟팅을 크게 변경하면 순간적으로 CPC 효율이 크게 변동할 수 있어요 집행 중에는 조금씩 변경하면서 효율을 확인하여 운영하는 것을 권장해요.

#### 자동 입찰 전환 최대

* 전환을 최대화하기 위해 주어진 일 예산을 최대한 소진하면서도 가장 효율적인 CPA(전환당 단가)를 얻기 위해 토스가 자동으로 입찰을 결정해요.
* 목표 비용 설정 (tCPA)
  * 목표 전환당 비용(tCPA)을 달성하기 위해 전환 가능성이 높은 유저에게 토스가 자동으로 입찰을 결정해요.
  * 캠페인 목적 '잠재고객 모으기' 에만 적용 가능해요.
  * tCPA 운영 주의 사항
    * 머신러닝 최적화에 시간이 소요되므로, 전환수 30건이 모일때까지는 입찰 방식을 유지하는 것을 권장해요.
    * 전환수가 모이지 않거나 예산 소진이 미비한 경우, tCPA 값을 적절하게 높여서 충분한 소진과 전환수를 확보할 수 있도록 해주세요.
* 자동 입찰 전환 최대화를 선택하여 운영하는 경우 소진 방식도 시스템이 자동으로 운영해요.
  * \[일반 소진], \[빠른 소진] 옵션은 선택 및 적용이 불가능해요.
* 캠페인 집행중에는 입찰 방식을 아래 조건에 따라 바꿀 수 있어요.
  * 광고 세트 생성 후에는 \[전환 최대화 / 직접 입찰 CPC] <> \[CPM] 사이에 입찰방식 변경이 불가해요.
  * \[자동 입찰 전환 최대화] <> \[직접 입찰 CPC] 사이의 입찰방식 변경은 언제든 변경 가능해요.

#### 직접 입찰 CPC

* 직접 단가를 설정하여 입찰하는 방식으로 클릭 당 과금되는 입찰 방식이에요.

#### 직접 입찰 CPM

* 광고가 1,000번 노출될 때마다 과금되는 입찰 방식이에요.
