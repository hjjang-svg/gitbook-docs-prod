# 한 줄 배너

## 1. 한 줄 배너란?

<figure><img src="../../../.gitbook/assets/1. 한줄 배너란_ (1).png" alt=""><figcaption></figcaption></figure>

가로로 긴 띠 형태의 배너를 뜻해요. 작은 1:1 이미지와 문구로 이루어져 있어요.

#### 2-3) 예시

**안전 노출 영역을 지켜주세요**

| **`DO`**         | **`Don't`**          |
| ---------------- | -------------------- |
| 안전 노출 영역을 지킨 이미지 | 안전 노출 영역을 지키지 않은 이미지 |

**카피와 연관된 이미지를 써주세요**

| **`DO`**     | **`Don't`**  |
| ------------ | ------------ |
| 카피와 어울리는 이미지 | 카피와 상관없는 이미지 |

**적절한 크기와 밀도를 지켜주세요**

| **`DO`**           | **`Don't`**                                |
| ------------------ | ------------------------------------------ |
| 어떤 요소인지 알 수 있는 이미지 | 인식하기 힘든 작고 복잡한 이미지 or 큰 영역에 비어 보이게 들어간 이미지 |

**붉은 톤, 고채도 색상은 쓸 수 없어요**

| **`DO`**                    | **`Don't`** |
| --------------------------- | ----------- |
| 브랜드 ・ 제품과 어울리는 색상을 쓴 이미지    |             |
| • 브랜드 컬러가 붉은 톤인 경우는 쓸 수 있어요 | 강한 형광색 이미지  |

**기능으로 보이는 이미지는 쓸 수 없어요**

| **`DO`**            | **`Don't`**      |
| ------------------- | ---------------- |
| 광고임을 알 수 있는 이미지와 문구 | 기능으로 보이는 이미지와 문구 |

**분할, 잘린 이미지는 쓸 수 없어요**

| **`Don't`**        | **`Don't`** |
| ------------------ | ----------- |
| 분할되어 시인성이 떨어지는 이미지 | 잘려보이는 이미지   |

## 3. 문구

#### 3-1) 공통

<table><thead><tr><th width="241.204833984375">규칙</th><th>내용</th></tr></thead><tbody><tr><td>일반</td><td><ul><li>혜택・정보가 드러나는 문구</li><li>명사형 또는 ~해요체로 기재</li></ul></td></tr><tr><td>평어체 (반말) ・ 맞춤법</td><td><ul><li>평어체(반말), 맞춤법에 어긋나는 표현 사용 불가</li></ul></td></tr><tr><td>신조어 ・ 밈</td><td><ul><li>신조어, 밈, 초성 사용 불가</li></ul></td></tr><tr><td>특수문자</td><td><ul><li>과도한 강조 ・ 과장 표현의 불필요한 특수 문자는 사용 제한</li><li><p>사용할 수 있는 특수문자</p><ul><li><strong><code>% &#x26; - + = · ? / → ‘ ’ " " ~ ! ( ) , . []</code></strong></li></ul></li><li><p> 허용된 특수 문자라 하더라도 반복 사용 불가</p><ul><li>예: <code>!!!</code>, <code>~~</code>, <code>??</code>, <code>%%</code></li></ul></li><li> 온점(.)은 문장의 끝에 사용 불가</li><li>특수 문자를 사용해 공지,알림성 정보로 보이는 경우, 심사가 반려될 수 있음</li></ul></td></tr><tr><td>조건부 혜택</td><td><ul><li>가입 ・ 응모와 같이 조건이 있는 혜택은 광고 문구 내에 반드시 기재</li><li>랜딩 페이지에서 확인할 수 없는 혜택 ・ 정보는 사용 불가</li></ul></td></tr><tr><td>색상</td><td><ul><li>⚠️ 광고 문구 색상 변경 불가</li></ul></td></tr></tbody></table>

#### 3-2) 문구 규격

| 규칙            | 내용                                                                                                   |
| ------------- | ---------------------------------------------------------------------------------------------------- |
| 짧은 주요 문구 (18) | <ul><li>최소 5자 ~ 최대 18자</li><li>이미지에 로고가 없는 경우, 브랜드명 표기 필수</li></ul>                                  |
| 보조 문구 (18)    | <ul><li>최소 5자 ~ 최대 18자</li><li>이미지에 로고가 없는 경우, 브랜드명 표기 필수</li><li>⚠️ 주요 문구에 쓰인 혜택/정보 중복 불가</li></ul> |

#### 3-3. 예시

**짧고 쉽게, 누구나 이해할 수 있게 써주세요**

| **`DO`**                               | **`Don't`**                                    |
| -------------------------------------- | ---------------------------------------------- |
| <p>최대 2% 할인, Wide 카드<br>토스뱅크에서 만나기</p> | <p>”~2%할인” 완전 new 카드<br>토스뱅크에서 바로 만날 수 있어요</p> |

**오탈자 ・ 띄어쓰기를 확인해주세요**

| **`DO`**                           | **`Don't`**                                                              |
| ---------------------------------- | ------------------------------------------------------------------------ |
| <p>여름 맞이 이벤트가 열렸어요<br>토스에서 해보기</p> | <p>여름 <code>맏이</code> 이벤트<code>가열렸어요</code><br>토스에서 <code>헤보기</code></p> |

**문장 끝 마침표(.)는 쓸 수 없어요**

| **`DO`**                             | **`Don't`**                                        |
| ------------------------------------ | -------------------------------------------------- |
| <p>나만의 카드 디자인 확인해요<br>토스 Wide 카드</p> | <p>나만의 카드 디자인 확인해요<code>.</code><br>토스 Wide 카드</p> |

**중복되는 문구는 쓸 수 없어요**

| **`DO`**                        | **`Don't`**                                      |
| ------------------------------- | ------------------------------------------------ |
| <p>나의 요금제 테스트<br>5개 문제에 답하기</p> | <p>나의 요금제 테스트<br><code>내 요금제 지금 테스트</code>해요</p> |

**랜딩 페이지와 다른 혜택은 쓸 수 없어요**

| **`DO`**                                                        | **`Don't`**                                                               |
| --------------------------------------------------------------- | ------------------------------------------------------------------------- |
| <p>7개월 동안 월 14,000원<br>토스모바일 요금제 보기<br><br>→ 7개월 이후 44,800원</p> | <p><code>무조건</code> 월 14,000원<br>토스모바일 요금제 보기<br><br>→ 7개월 이후 44,800원</p> |

**기능으로 보이는 문구는 쓸 수 없어요**

| **`DO`**                           | **`Don't`**                                                                                                                                                        |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <p>나만의 맞춤 알바 확인하기<br>토스알바에서 보기</p> | <p><code>[알림]</code> 새로운 알바 메세지 <code>(1)</code><br>토스 알바에서 보기<br><br>다른 예시)</p><ul><li>바로 10만원 받기 (X)</li><li>미확인 내역이 있어요 (X)</li><li>80,000원 입금 완료 (X)</li></ul> |

**불안 ・ 조급함을 자극하는 문구는 쓸 수 없어요**

| **`DO`**                          | **`Don't`**                                                                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| <p>토스에서 환급금 확인해요<br>버튼 눌러서 보기</p> | <p>정말 환급금 놓치시겠습니까?<br>사라지는 내 환급금 토스에서 조회<br><br>다른 예시)</p><ul><li>당장~하지 않으면 안된다 (X)</li><li>~안하면 손해 (X)</li><li>~놓치는 혜택 (X)</li></ul> |

**반복 ・ 의미없는 특수문자는 쓸 수 없어요**

| **`DO`**                                                                    | **`Don't`**                                                                     |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| <ul><li>최대 10% 할인</li><li>지금 가입하면 혜택까지!</li><li>스킨 케어 BEST 1+1 혜택</li></ul> | <ul><li>지금이!! 기회입니다! →</li><li>가입하면 · 혜택이? !</li><li>(알림)즉시 수령 가능 현금+</li></ul> |

## 5. 연결 URL

#### 5-1) 공통

<table><thead><tr><th width="333.939208984375">규칙</th><th>내용</th></tr></thead><tbody><tr><td>일반</td><td><ul><li>광고의 내용과 연결되는 랜딩 페이지</li></ul></td></tr><tr><td>유저가 접속할 때 이상이 없어야함</td><td><ul><li><p>웹으로 랜딩</p><ul><li>⚠️ 오류 ・ 접근 불가 페이지, 이벤트 오픈 전 페이지는 사용 불가<br>‣ 랜딩 페이지를 만들기 전 심사를 받는 경우, 증빙 자료를 함께 제출하면 가능</li><li>접속하는데 5초 이상 걸리는 경우, 브릿지 페이지 제작</li></ul></li><li><p>앱으로 랜딩</p><ul><li>앱 미설치 유저는 앱 스토어・플레이스토어로 랜딩</li></ul></li></ul></td></tr><tr><td>랜딩 페이지의 내용과 소재 내용이 일치해야 함</td><td><ul><li>⚠️ 랜딩 페이지에서 확인할 수 없는 혜택 ・ 정보는 사용 불가</li><li>⚠️ 가입 ・ 응모와 같이 조건부 혜택은 광고 문구에 기재</li></ul></td></tr><tr><td>URL 주소는 영문으로 제출</td><td><ul><li>⚠️ 주소에 한글이 있는 경우에는 사용 불가</li><li>링크 내에 <code>{ } ^ #</code> 문구가 있으면 반려될 수 있음</li><li>^ 대신 _(언더바) 사용 권장</li><li><code>http://</code>는 사용 불가 → <code>https://</code> 사용 권장</li></ul></td></tr><tr><td>URL 축약 불가</td><td><ul><li>앱플라이어로 만든 윈링크의 경우, 피라미터가 단축되지 않은 원본 제출</li><li>⚠️ 숏 링크 / 단축 URL 사용 불가(비틀리 포함)</li></ul></td></tr><tr><td>기타</td><td><ul><li>이 외의 이유로 문제가 있는 경우, URL 수정을 요청할 수 있음</li><li>그 외 공통으로 적용되는 규정은 <a href="https://toss-ads.gitbook.io/guide/policy/creativeguide">소재 심사 규정</a> 참고</li></ul></td></tr></tbody></table>

#### 5-2) 예시

**연결할 페이지에 오류가 없는지 확인해주세요**

| **`DO`**                 | **`Don't`**               |
| ------------------------ | ------------------------- |
| 잘 열리고, 문제없이 동작하는 페이지 URL | 링크 주소에 오류가 있거나, 빈 페이지 URL |

**연결할 페이지를 만들기 전이라면, 꼭 증빙 자료를 첨부해주세요**

| **`DO`**                | **`Don't`**          |
| ----------------------- | -------------------- |
| 어떤 페이지를 사용할 것인지 증빙자료 제출 | 빈 페이지 제출 또는 증빙 자료 누락 |

{% hint style="info" %}
**유의사항**

* 브랜드와 관련된 정보가 허위 사실로 밝혀질 경우, 집행이 제한될 수 있어요.
  * 이미 승인된 소재라도 집행 제한 또는 중단될 수 있어요.
* 문구에 기재된 정보가 허위 사실로 밝혀질 경우, 집행이 제한될 수 있어요.
  * 이미 승인된 소재라도 집행 제한 또는 중단될 수 있어요.
* 중복 ・ 유사한 내용의 소재를 반복적으로 등록하는 경우, 집행이 제한될 수 있어요
* 사용자 디바이스 설정이나 기종에 따라 이미지가 상하 ・ 좌우로 조금 잘려 보이거나, 소재 미리보기 화면과 다르게 보일 수 있어요.
{% endhint %}
