# 유용한 기능

## 소재 가져오기 <a href="#import-creative" id="import-creative"></a>

<figure><img src="../.gitbook/assets/1.유용한 기능_가져오기 (1).png" alt=""><figcaption></figcaption></figure>

소재 설정 화면에서 기존 소재들을 간편하게 살펴보고 소재명으로 검색해서 가져올 수 있는 기능이에요.

* **사용 방법**
  * 캠페인 생성 > 소재 설정 > 우측 상단 가져오기 클릭
    * 기존 소재들을 한 눈에 살펴보고 필요한 소재를 선택해서 새로운 캠페인에 간편하게 불러올 수 있어요.
      * 소재명으로 검색하면 원하는 소재를 빠르게 찾을 수 있어요.

## 토스 앱에서 미리보기

<figure><img src="../.gitbook/assets/2.유용한 기능_토스 앱에서 미리보기.png" alt=""><figcaption></figcaption></figure>

휴대폰에서 QR 코드를 스캔하거나 링크를 복사해서 광고 소재가 토스 앱에서 어떻게 보이는지 광고 화면을 미리 확인할 수 있는 기능이에요.

* **사용 방법**
  * 캠페인 생성 > 소재 설정 > 우측 상단 미리보기 클릭
  * 해당 화면에서 토스 앱 아이콘 클릭하면 토스 앱에서 미리볼 수 있는 QR코드를 확인할 수 있어요.
    * 생성된 **QR** **코드**를 휴대폰 카메라로 스캔 혹은 링크 복사 → 복사한 링크 모바일 환경에서 열어보기
  * 모바일 환경에서 소재 확인
    * 토스 앱이 설치되지 않은 경우 미리보기 기능을 사용하기 어려워요.
      * 미리보기 (토스 앱) 화면에서는 내 소재의 랜딩 페이지를 눌러보는 것 외에 다른 기능은 동작하지 않아요.
    * 소재를 수정했다면 새로운 QR 코드와 링크를 복사해서 확인해주세요.
* **유의 사항**
  * 미리보기는 대표 예시로, 실제 지면 및 사용자의 기기 설정에 따라 줄바꿈, 이미지 잘림 등이 발생할 수 있어요.
  * 잠재고객 모으기 정보입력 양식은 미리보기 기능을 지원하지 않아요.
  * 랜딩 URL 유형에 따라 지원 방식이 달라요.
    * 딥링크: 중괄호 { } 가 포함된 딥링크는 랜딩 페이지로 연결되지 않아요.
    * MMP: 미리보기 기능을 통해 접속한 경우, 성과 측정에서 제외되어요.
