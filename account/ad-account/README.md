# 광고계정 생성·운영

광고계정은 토스애즈에서 광고를 집행하기 위한 최소 단위예요. 이 문서에서는 광고계정을 만들고, 구성원을 초대하고, 더 이상 사용하지 않는 광고계정을 삭제하는 방법까지 안내해요.

## 광고계정이란?

<figure><img src="../../.gitbook/assets/image (27) (1).png" alt=""><figcaption></figcaption></figure>

광고계정은 토스애즈에서 광고를 집행하기 위한 최소 단위로, 비즈니스 그룹 안에 만들 수 있어요.

### 광고계정 권한 구분

광고계정 권한은 크게 두 가지로 나뉘어요.

| 구분  | 할 수 있는 일                                                                                      |
| --- | --------------------------------------------------------------------------------------------- |
| 계정장 | <ul><li>계정 내 모든 광고 조회와 관리</li><li>계정 구성원 초대 및 관리</li><li>캠페인 집행 중단 처리</li><li>환불 신청</li></ul> |
| 구성원 | 계정 내 모든 광고 조회와 관리                                                                             |

## 광고계정 만들기

{% stepper %}
{% step %}

* 비즈니스 그룹의 구성원 또는 그룹장 권한이 있어야 광고계정을 만들 수 있어요.

<figure><img src="../../.gitbook/assets/image (51) (1).png" alt=""><figcaption></figcaption></figure>

* 광고계정명은 사업자명과 같게 입력하지 않아도 되고, 만든 뒤에도 언제든지 수정할 수 있어요.

<figure><img src="../../.gitbook/assets/image (52) (1).png" alt=""><figcaption></figcaption></figure>

### **광고계정 생성을 신청해요**

* 신청을 완료하면 비즈니스 그룹장에게 심사 요청이 전달돼요.

<figure><img src="../../.gitbook/assets/image (53).png" alt=""><figcaption></figcaption></figure>

{% step %}
### **그룹장이 광고계정 생성을 승인해요**

* 비즈니스 그룹의 구성원이 새롭게 신청한 광고계정은 그룹장이 승인해야 생성이 완료돼요.
* 광고계정 승인은 **토스애즈 로그인 > 그룹 관리 > 승인 요청**에서 진행할 수 있어요.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
**광고 대행사이신가요?**

광고 대행을 목적으로 광고계정을 생성하시고자 하시며, 대행 수수료를 지급 받고자 하실 경우 아래 내용을 확인 해주세요.

**\[토스애즈 광고 대행]**

광고 대행으로 수수료를 지급 받으시려면, 먼저 대행 계약체결이 필요해요. (대행수수료는 광고대행사가 토스를 대신하여 토스 광고를 영업/운영/정산업무를 진행하며 광고주의 광고 셀프서빙함에 토스가 광고대행사에게 지급하는 금액이에요.)

대행 수수료 지급 조건인 '광고대행사'의 경우 아래의 조건에 해당해야 하며 사전 협의된 수수료가 지급돼요.

1. 토스와 사전 협의를 통해 광고 등 업무제휴계약체결이 되어 있어야 해요.
2. 대행사는 사업자등록 상 '광고대행업' 종목이 포함된 곳이어야 해요.
3. 수수료 지급 대상 광고는 광고대행사가 아닌 광고주의 광고건이어야 하며 광고주를 대신하여 광고신청/운영/정산업무를 진행하는 건이어야 해요.

위 조건에 해당하신다면, adsbiz.team@toss.im 으로 대행 계약 체결 요청 메일을 발송해주세요.
{% endhint %}

## 광고계정에 참여하기

광고를 집행하려면 반드시 **광고계정에 초대되어 있어야 해요.**

* 광고계정이 이미 만들어져 있다면, **계정장에게 구성원을 직접 초대해야 해요.**
  * 구성원이 계정장에게 광고계정 초대를 요청하는 기능은 제공하지 않아요.
* 한 사람이 여러 개의 광고계정에 참여할 수 있어요.
* 계정장이 초대하면 이메일로 안내드려요. 초대 메일을 받았다면 토스애즈에 로그인 한 상태로 **\[내용 보기]**&#xB97C; 눌러 초대를 수락해주세요.

## 광고계정 운영하기

### 내 광고계정 확인하기

* 내가 참여 중인 광고계정은 왼쪽 위 메뉴에서 내 광고계정 탭을 선택해 확인할 수 있어요.
* 광고계정을 추가하려면 비즈니스 그룹명 옆 \[+] 버튼을 클릭해주세요.

<figure><img src="../../.gitbook/assets/image (56) (1).png" alt=""><figcaption></figcaption></figure>

### 구성원 초대하기 <a href="#invite-members" id="invite-members"></a>

* 계정장은 광고계정에 구성원을 초대할 수 있어요. 구성원을 초대하려면 **\[광고계정 구성원]** 탭을 눌러주세요.

<figure><img src="../../.gitbook/assets/image (57) (1).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
**구성원을 초대할 때 꼭 확인해주세요**

* 새로운 구성원을 초대하면 그 구성원의 계정 활동에 대한 관리 책임은 모두 초대를 보낸 사용자에게 있어요.
* 부여하는 권한 레벨에 따라 광고계정의 다른 구성원 이름, 이메일, 전화번호 등 개인정보를 볼 수 있으므로 구성원 초대와 관리에 주의해야 해요.
* 부여하는 권한 레벨에 따라 광고 운영, 구성원 초대 등 모든 관리와 운영 기능을 사용할 수 있으므로 사용자에게 맞는 권한 레벨을 지정해야 해요.
* 초대받아 광고계정에 참여한 사용자는 부여받은 권한 레벨로 접근할 수 있어요. 운영 중인 해당 계정의 권한 해제와 권한 레벨 변경도 할 수 있어요.
{% endhint %}

## 광고계정 삭제 <a href="#a-d-account-delete" id="a-d-account-delete"></a>

광고계정을 더 이상 사용하지 않으려면 삭제할 수 있어요. 광고계정 삭제는 **광고계정 정보** **>** **계정 삭제하기** 버튼을 눌러 진행할 수 있어요.

<figure><img src="../../.gitbook/assets/image (58) (1).png" alt=""><figcaption></figcaption></figure>

* 광고계정 삭제는 그룹장 권한을 가진 구성원만 진행할 수 있어요.
* 아래 조건을 충족해야 계정을 삭제할 수 있어요.
  * 광고계정의 유상 머니 잔액이 0원인 경우
  * 모든 광고 캠페인의 집행이 완료된 경우
  * 모든 정산이 마무리된 경우
* 계정 삭제 버튼을 누른 뒤 삭제를 진행하면 최종적으로 광고계정 삭제가 완료돼요.

{% hint style="warning" %}
운영 중인 광고계정을 다른 비즈니스 그룹으로 옮기고 싶다면 삭제하지 말고 [광고계정 이관](control.md)을 신청해주세요.
{% endhint %}

{% hint style="danger" %}
광고계정을 삭제하면 아래 항목을 되돌릴 수 없으니 신중히 결정해주세요.

* 캠페인 데이터
* 소재 데이터
* 광고 결제 내역
* 전환 추적 데이터
{% endhint %}
