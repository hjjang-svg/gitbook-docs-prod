# 성과 보기

## 1. 성과 조회하기

#### 기본 성과 조회

라이브 마켓 페이지에 접속하시면 집행 완료된 광고들의 성과를 확인하실 수 있어요.

기본적으로 아래 지표를 확인하실 수 있어요.

* 라이브 알림 신청 수 : 공개 예정인 라이브 방송의 알림을 신청한 총 횟수예요.
* 라이브 상세페이지 노출 수 : 라이브 방송 상세 페이지가 사용자에게 노출된 총 횟수예요. 방송 중, 방송 종료, 공개 예정 상태를 모두 포함해요.
* 라이브 상세페이지 도달 수 : 라이브 방송 상세 페이지를 한 번 이상 본 사용자 수예요.
* 라이브 보고 랜덤 포인트 받기 CTA 클릭 수 : 방송 중인 라이브 상세 페이지에서 라이브 보고 랜덤 포인트 받기 버튼이 클릭된 총 횟수예요.
* 라이브 보고 랜덤 포인트 받기 CTA 클릭자 수 : 라이브 보고 랜덤 포인트 받기 버튼을 한 번 이상 클릭한 사용자 수예요.

## 2. 성과 다운로드하기

#### 캠페인 별 성과 다운로드 <a href="#live-performance-download" id="live-performance-download"></a>

진행하신 광고 캠페인별로 성과를 다운로드 하실 수 있어요.

성과 다운로드의 경우 집행 완료 후 다음날 오전 11시 이후에 다운로드 하실 수 있어요.

<figure><img src="../../.gitbook/assets/마이브 마켓_성과 확인하기.png" alt=""><figcaption></figcaption></figure>

다운로드를 진행하시면 엑셀 파일로 성과를 확인하실 수 있어요.

엑셀 파일에서는 위 기본 성과 조회 지표 외 성/연령별 방송 시청 유저 수를 확인하실 수 있어요.
