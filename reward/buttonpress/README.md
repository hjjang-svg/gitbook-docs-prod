# 버튼 누르기

> 버튼 누르기는 원하는 시간대에 원하는 만큼의 트래픽을 저렴한 단가로 확보할 수 있는 광고 상품이에요.

<figure><img src="../../.gitbook/assets/버튼누르기 (1).png" alt=""><figcaption></figcaption></figure>

* 토스 앱 **혜택 탭**에 리스트 형태로 노출돼요.
* 하루를 3시간씩 8개 시간대로 나누고, 사용자는 시간대마다 버튼을 눌러 포인트를 받을 수 있어요
* 버튼이나 상품 이미지를 누르면 광고주가 지정한 페이지로 이동해요.

#### 장점

* **시간대를 골라서 집행:** 고객 특성이나 광고 목적에 맞춰 원하는 시간대를 골라 집행할 수 있어요.
* **적은 예산으로 시작:** 최소 10만 트래픽부터 부킹할 수 있어 적은 예산으로도 시작할 수 있어요.
* **필요한 만큼만 유연하게:** 시간대별로 원하는 트래픽만 골라서 집행할 수 있어요.

#### **시간대별 예약 가능 구좌**

* 특정 시간대를 정하지 않아도 미지정 구좌로 트래픽을 확보할 수 있어요.
* 최대 트래픽 안에서 원하는 만큼만 선택할 수 있어요. (최소 10만부터 10만 단위)
* 시간대별로 남은 트래픽은 광고주 센터에서 확인할 수 있어요.

#### 단가

| 구분     | 과금 방식 | 단가  |
| ------ | ----- | --- |
| 시간 지정  | CPC   | 20원 |
| 시간 미지정 | CPC   | 18원 |

#### 집행 방법

1. 광고주 센터에서 예약할 수 있는 시간대와 트래픽을 확인해요.
2. 원하는 시간대가 있으면 **시간 지정**, 없으면 **시간 미지정**을 고르고 트래픽을 선택해요.
3. 광고비를 결제한 뒤 소재를 등록해요.

#### **소재 유형**&#x20;

| 구분     | 특징                                                                                                                                   |

| 카탈로그형  | <p>• 대표 이미지와 추천 상품 3개를 함께 보여줄 수 있어요.<br>• 버튼과 추천 상품 3개에 각각 링크를 걸 수 있고, 하나의 링크로 다 적용할 수도 있어요.<br>• 기획전이나 이벤트를 홍보하고 싶을 때 활용하기 좋아요.</p> |
