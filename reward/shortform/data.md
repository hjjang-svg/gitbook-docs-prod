# 성과 보기

## 1. 성과 조회하기 <a href="#view-performance" id="view-performance"></a>

#### 기본 성과 조회 <a href="#basic-performance" id="basic-performance"></a>

숏폼 페이지에 접속하시면 집행 완료된 광고들의 성과를 확인하실 수 있어요.

기본적으로 아래 지표를 확인하실 수 있어요.

* 숏폼 상세 노출 수 : 라이브 전 상세 페이지 노출 수
* 숏폼 노출 수 : 숏폼 영상 노출 수
* 상품 상세 클릭 수 : 상품으로 이동한 유저 수

## 2. 성과 다운로드하기 <a href="#download-performance" id="download-performance"></a>

#### 캠페인 별 성과 다운로드 <a href="#download-by-campaign" id="download-by-campaign"></a>

진행하신 광고 별로 성과를 다운로드 하실 수 있어요. 다운로드는 집행 시작 1시간 이후부터 가능해요.

<figure><img src="../../.gitbook/assets/숏폼_성과 확인하기.png" alt=""><figcaption></figcaption></figure>

다운로드를 진행하시면 엑셀 파일로 성과를 확인하실 수 있어요.
