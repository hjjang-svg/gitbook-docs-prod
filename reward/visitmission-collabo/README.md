# 일주일 방문 미션(협력광고)

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2F17vLpleXPnAQ34szTeAd%2Fimage%20(6).png?alt=media&#x26;token=1eaca189-dd78-4999-a5e7-0df86c710ce9" alt=""><figcaption></figcaption></figure>

### 광고 상품 소개

일주일 방문 미션은 상품 좋아요 누르기, 장바구니 담기, 구경하기 같은 미션을 통해 사용자의 인게이지먼트를 올릴 수 있는 광고 상품이에요. 단기간에 트래픽을 확보할 뿐 아니라 탐색 과정에서 자연스럽게 구매까지 유도해요.

* 토스 앱 > 혜택 탭 > 일주일 방문 미션에 리스트 형식으로 노출돼요.
* 미션을 시작하면 누르면 광고주가 지정한 올리브영 상세 페이지로 이동해요.
* 미션을 완료한 사용자에게 포인트가 지급돼요.
* 올리브영에서 발생한 구매 성과를 트래킹할 수 있어요.

### **미션 종류**

|            |                                     |
| ---------- | ----------------------------------- |
| 상품 구경하기    | 올리브영 상품 상세 페이지로 방문과 체류를 유도하는 미션이에요. |
| 상품 담기      | 올리브영에서 상품을 장바구니에 담게 하는 미션이에요.       |
| 상품 좋아요 누르기 | 올리브영에서 상품 좋아요 누르게 하는 미션이에요.         |

* 올리브영과 함께하는 협력 광고 모델로 **올리브영에 입점한 브랜드만 집행**할 수 있어요.

### 캠페인 생성하기

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2FybzICrxA1JcN4VBMpAJE%2F%E1%84%8F%E1%85%A2%E1%86%B7%E1%84%91%E1%85%A6%E1%84%8B%E1%85%B5%E1%86%AB%20%E1%84%89%E1%85%A2%E1%86%BC%E1%84%89%E1%85%A5%E1%86%BC%20(8).png?alt=media&#x26;token=4c6437e3-f948-4a93-bb16-50a223afc2c8" alt=""><figcaption></figcaption></figure>

**메뉴 선택**

* 왼쪽 메뉴에서 일주일 방문 미션을 클릭 후, 우측 상단 ‘캠페인 생성’ 버튼을 클릭해 주세요.

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2FGMOe6k0E6V7iMd9uw8hI%2F%E1%84%83%E1%85%AE%E1%84%83%E1%85%AE%E1%84%8D%E1%85%B5%E1%86%A8_%E1%84%89%E1%85%A5%E1%86%BC%E1%84%80%E1%85%AA%20%E1%84%92%E1%85%AA%E1%86%A8%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%92%E1%85%A1%E1%84%80%E1%85%B5.png?alt=media&#x26;token=1c4ef91a-0a89-457c-bd33-c2f3bee9705a" alt=""><figcaption></figcaption></figure>

1. **캠페인 선택**
   * 처음 화면에 들어오면 바로 왼쪽 목록에서 캠페인이 선택되어 있어요.
2. **캠페인명 입력**
   * 캠페인 이름을 입력하는 영역이에요. (100자 까지 입력할 수 있어요.)
   * 기본으로 년월일시로 자동 생성되고, 수정할 수 있어요.
3. **집행 기간 선택**
   * 하루 단위로 최소 하루 \~ 최대 2주 선택할 수 있어요.
   * 과거 \~ 오늘은 선택할 수 없고, 다음날부터 선택할 수 있어요.
4. **전환 추적 연동**

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2FMksWaXCjrWrL6H58oIMG%2Fimage%20(17).png?alt=media&#x26;token=e298b55d-7869-4a5b-9a3d-32298f13f6a1" alt=""><figcaption></figcaption></figure>

* 전환 추적 코드를 이미 사용하고 있어요.
  * 선택하기- 드롭다운 - 사용할 전환 추적 코드를 선택해주세요.

<figure><img src="https://1103230780-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F6C6VnjnrKC0ixISOKw0d%2Fuploads%2FLTtjIXBFJ7kYiTVnFmDi%2Fimage%20(18).png?alt=media&#x26;token=b93f6983-a06e-4396-b0bb-e3c04d337dad" alt="" width="563"><figcaption></figcaption></figure>

* 전환 추적 코드를 처음 설정해요.
  * 코드 추가 클릭 - 전환 추적 코드 이름 입력 -대표 랜딩 URL 입력
    * onlBrndCd 파라미터가 포함된 올리브영 브랜드관 대표 URL을 입력해 주세요.
    * 생성 클릭
* 선택하기- 드롭다운 - 사용할 전환 추적 코드를 선택해주세요.

5. **약관 동의**
   * 광고 집행 시 필수적으로 확인 필요한 위약금 정책 및 운영, 정산 관련 내용을 안내하고 있어요.
   * 광고 생성 전에 반드시 확인하고 동의 여부를 체크해주세요.
