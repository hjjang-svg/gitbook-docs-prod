# 성과 보기

## 1. 성과 조회하기

#### 기본 성과 조회

행운퀴즈 페이지에 접속하시면 집행 완료된 광고들의 성과를 확인하실 수 있어요.

기본적으로 아래 지표를 확인하실 수 있어요.

* 퀴즈 리스트 노출 수
* 퀴즈 진입자 수
* 힌트 클릭 수
* 힌트 클릭자 수
* 퀴즈 완료 수
* 퀴즈 완료자 수
* 추가 혜택 화면 노출 수
* 추가 혜택 버튼 클릭 수

#### 전환 성과 조회

행운퀴즈 광고의 전환 성과를 확인하실 수 있어요. 전환 성과는 광고를 통해 유저가 실제로 수행한 행동을 측정한 지표예요.

아래 전환 지표를 확인하실 수 있어요.

* 상세페이지 조회 수
* 상세페이지 조회율
* 앱 설치 수
* 앱 설치당 비용 (CPI)
* 앱 설치율
* 회원가입 수
* 회원가입당 비용
* 회원가입률
* 장바구니 담기 수
* 장바구니 담기당 비용
* 장바구니 담기 전환율
* 구매 완료 수
* 구매당 비용 (CPP)
* 구매 전환율
* 구매 전환 매출액

{% hint style="info" %}
**참고:** 행운퀴즈의 전환율 지표(상세페이지 조회율, 앱 설치율, 회원가입률, 장바구니 담기 전환율, 구매 전환율)는 **힌트 클릭 수**를 분모로 계산돼요. 예를 들어, 구매 전환율 = 구매 완료 수 / 힌트 클릭 수 x 100 이에요.
{% endhint %}

## 2. 성과 다운로드하기

#### 성과 다운로드

진행하신 광고 별로 성과를 다운로드 하실 수 있어요.

다운로드를 진행하시면 엑셀 파일로 성과를 확인하실 수 있어요.

엑셀 파일에서는 기본 성과 지표와 전환 성과 지표외에 **성/연령 별 클릭 수 데이터**를 확인하실 수 있어요.
